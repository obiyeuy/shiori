# 工作台契约

`/workspace` 全部页面复用 owner hook 与 no-store 响应；写操作必须同源。WorkspaceService 写事务再次锁定并验证当前 owner 会话，随后记录审计。设置及 OAuth 绑定需要最近 10 分钟认证；密码和解绑使用 P0 认证服务并撤销其他会话。GitHub 绑定由同源 POST 发起，OAuth attempt 关联原会话，回调校验会话一致并重新检查近期认证。

内容每页 20 条，默认不显示归档。标签多选组内 OR，类型/公开/编辑/排期/归档/关键词等组间 AND。编辑状态比较草稿与公开 payload，不以保存时间判断。归档不改变公开指针；排期异常与概览仍能发现已归档内容。

系列只接受文章/笔记，每篇至多一个系列。事务 advisory lock 串行化成员替换，显式保存才改变公开关系；上下按钮可键盘操作，边界按钮禁用。重命名标签立即改变公开名称，旧版本标签快照保持不变。

站点设置提供人工精选/作品顺序、站名/介绍、Banner/手机图/焦点/署名和 Giscus 白名单配置。Banner 只有就绪 display 变体可被授权公开，原图保持受保护。图片文件、媒体和旧关系不会因修改设置而清理。系列封面要求已有公开 display 授权。

媒体页面提交原始文件到 P1 上传接口，失败/pending/processing 可显式重试，容量门禁继续生效。服务入口仅保存 URL 和人工状态/时间，不探测、不嵌入外部页面。

运行概览只读取记录；事件时间和采集时间分开显示。排期新鲜度 2 分钟，容量 5 分钟，备份/异地/评论导出 26 小时。备份记录读取与定时采集由 P4 完成，未配置不显示成功。页面不持有 Docker、root 或 SSH 权限。
