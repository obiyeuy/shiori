<blockquote class="tldr"><div class="tldr__body"><i class="strapi-icons ph-fill ph-newspaper-clipping" style="color:inherit"></i> <strong>Page summary<!-- -->:</strong><br><p>Media Library providers extend Strapi&#x27;s upload capabilities to store files in external services like AWS S3 or Cloudinary. You can install official providers, configure them in <code>/config/plugins</code>, create custom providers, or set up private providers with signed URLs for secure asset access.</p></div></blockquote>
<p>The <a href="/cms/features/media-library">Media Library</a> feature is powered by a back-end server package called Upload which leverages the use of providers.</p>
<p>By default Strapi provides a provider that uploads files to a local <code>public/uploads/</code> directory in your Strapi project. Additional providers are available and add an extension to the core capabilities of the plugin. Use them to upload your files to another location, such as AWS S3 or Cloudinary.</p>
<p>Strapi maintains official providers, discoverable via the <a href="https://community.strapi.io/marketplace" target="_blank" rel="noopener noreferrer">Marketplace<i class="strapi-icons ph-fill external-link ph-arrow-square-out" style="color:inherit"></i></a>. Community-maintained providers are also available via <a href="https://www.npmjs.com/search?q=strapi%20provider" target="_blank" rel="noopener noreferrer">npm<i class="strapi-icons ph-fill external-link ph-arrow-square-out" style="color:inherit"></i></a>.</p>
<p>A provider can be configured to be <a href="#private-providers">private</a> to ensure asset URLs will be signed for secure access.</p>

<h2 class="anchor anchorWithStickyNavbar_LWe7" id="configuring-providers">Configuring providers<a href="#configuring-providers" class="hash-link" aria-label="Direct link to Configuring providers" title="Direct link to Configuring providers">​</a></h2>
<p>Newly installed providers are enabled and configured in <a href="/cms/configurations/plugins">the <code>/config/plugins</code> file</a>. If this file does not exist, create it first.</p>
<p>Each provider will have different configuration settings available. Please review the respective entry for that provider on dedicated pages below for the Strapi-maintained providers, or on the provider&#x27;s <a href="https://community.strapi.io/marketplace" target="_blank" rel="noopener noreferrer">Marketplace<i class="strapi-icons ph-fill external-link ph-arrow-square-out" style="color:inherit"></i></a> page.</p>
<p>The providers maintained by Strapi are the following. Clicking on a card will redirect you to a docs page with a configuration example:</p>

<li>Strapi has a default <a href="/cms/configurations/middlewares#security"><code>security</code> middleware</a> that has a very strict <code>contentSecurityPolicy</code> that limits loading images and media to <code>&quot;&#x27;self&#x27;&quot;</code> only. <h3 class="anchor anchorWithStickyNavbar_LWe7" id="configuration-per-environment">Configuration per environment<a href="#configuration-per-environment" class="hash-link" aria-label="Direct link to Configuration per environment" title="Direct link to Configuration per environment">​</a></h3>
<p>When configuring your provider you might want to change the configuration based on the <code>NODE_ENV</code> environment variable or use environment specific credentials.</p>
<p>You can set a specific configuration in the <code>/config/env/{env}/plugins.js|ts</code> configuration file and it will be used to overwrite the default configuration.</p>

<h3 class="anchor anchorWithStickyNavbar_LWe7" id="local-providers">Local providers<a href="#local-providers" class="hash-link" aria-label="Direct link to Local providers" title="Direct link to Local providers">​</a></h3>
<p>If you want to create your own provider without publishing it on npm you can follow these steps:</p>
<ol>
<li>Create a <code>providers</code> folder in your application.</li>
<li>Create your provider (e.g. <code>/providers/strapi-provider-&lt;plugin&gt;-&lt;provider&gt;</code>)</li>
<li>Then update your <code>package.json</code> to link your <code>strapi-provider-&lt;plugin&gt;-&lt;provider&gt;</code> dependency to the <a href="https://docs.npmjs.com/files/package.json#local-paths" target="_blank" rel="noopener noreferrer">local path<i class="strapi-icons ph-fill external-link ph-arrow-square-out" style="color:inherit"></i></a> of your new provider.</li>
</ol>

<h3 class="anchor anchorWithStickyNavbar_LWe7" id="private-providers">Private providers<a href="#private-providers" class="hash-link" aria-label="Direct link to Private providers" title="Direct link to Private providers">​</a></h3>
<p>You can set up a private provider, meaning that every asset URL displayed in the Content Manager will be signed for secure access.</p>
<p>To enable private providers, you must implement the <code>isPrivate()</code> method and return <code>true</code>.</p>
<p>In the backend, Strapi generates a signed URL for each asset using the <code>getSignedUrl(file)</code> method implemented in the provider. The signed URL includes an encrypted signature that allows the user to access the asset (but normally only for a limited time and with specific restrictions, depending on the provider).</p>
<p>Note that for security reasons, the content API will not provide any signed URLs. Instead, developers using the API should sign the urls themselves.</p>
