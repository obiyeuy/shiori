# 公开站壳层、搜索与音乐播放器设计规格

## 目标

继续优化公开站的整体个人空间体验，解决左右侧栏内容重复、搜索页独立感过强、banner 波浪缺少融合感的问题，并增加一个不绑定具体角色形象的站点 Favicon 与 Navidrome 音乐播放器。

## 已确认决策

- Favicon 不使用八奈见杏菜或任何角色图片。
- Favicon 使用抽象“开放窗口 + 四点星芒”标志：紫色主色、暖黄色点缀、清晰负形，适配 16px、32px 和移动端主屏图标。
- 音乐采用本站服务端代理 Navidrome 的方式。
- 服务器音乐服务为 `http://49.233.199.110:4533`，容器名 `navidrome`，音乐目录由服务器挂载；服务器凭据不进入前端、不提交 Git。
- 音乐播放器不自动播放，支持播放/暂停、进度、音量、播放列表和失败提示。

## 公共壳层

左栏只负责“个人空间与探索”：头像、站点简介、目录、标签和系列。移除统计、站点状态、快速链接等重复模块。

右栏只负责“当前页面上下文”：

- 首页：音乐播放器与最近更新；
- 内容详情：系列导航、上一篇/下一篇和相关文章；
- 栏目页：当前筛选和栏目说明；
- 搜索页：当前查询、类型和标签筛选摘要；
- 没有上下文时留白，不渲染虚构统计或占位模块。

移动端隐藏两侧栏，播放器转换为底部紧凑条，不能遮挡主要操作和正文。

## 搜索

保留 `/search` 路由和现有 GET 参数 `q`、`type`、`tag`、`page`。视觉上融入公共壳层：窄 banner 后进入搜索工作区，顶部搜索框横跨工作区，桌面端左侧筛选、右侧结果，移动端改为上下布局。

无关键词时显示真实栏目和标签入口；零结果、错误、超页和清除筛选均保留可操作反馈。结果使用标题、匹配片段、类型和日期的紧凑层次，不使用大型装饰标题卡。

## 波浪过渡

`SceneBanner` 使用一条主过渡曲线和一层低透明背景曲线。两层使用不同曲率、不同基线和反向极慢水平漂移，主曲线承担视觉边界，背景曲线只提供深度。栏目页和详情页降低波幅；减少动效或系统减少动效时完全静止。正文与场景保留明确间距，不使用负 margin 覆盖波浪。

## Favicon 与站点元信息

新增 SVG Favicon、32px PNG、Apple Touch Icon 和 Web Manifest；在根布局注入 `icon`、`shortcut icon`、`apple-touch-icon` 和 manifest 链接。SVG 使用内联渐变与负形，PNG 从同一 SVG 导出，避免多个版本视觉不一致。

## 音乐代理

新增服务端 Navidrome 客户端模块和公开只读接口：

- 服务端使用环境变量保存 Navidrome 地址、用户名和密码；
- 服务端生成短期会话或签名请求，浏览器只访问本站接口；
- 播放列表接口只返回曲目标题、艺术家、时长和本站代理播放 URL；
- 播放代理透传音频流、范围请求和必要的缓存头，不回显 Navidrome 凭据；
- 上游不可用、未配置凭据或曲目不存在时返回稳定错误 JSON，页面播放器显示可理解的失败状态；
- 不自动扫描、修改或删除服务器音乐文件。

## 验证

- 单元测试覆盖壳层职责、搜索双栏结构、波浪层数、Favicon 元信息和音乐接口错误处理。
- `pnpm check`、`pnpm lint`、`pnpm test:unit`、`pnpm build`。
- 本地部署到 `127.0.0.1:5181`，逐页检查首页、栏目、详情、搜索以及移动端；确认无横向溢出、播放器不遮挡内容、无控制台错误。
- 保留数据库、媒体、备份和服务器现有音乐文件；不推送远程。
