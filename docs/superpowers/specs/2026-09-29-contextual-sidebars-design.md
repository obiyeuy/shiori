# 个人空间与页面上下文侧栏设计

## 目标与边界

采用已确认的方案 A：左栏体现作者身份，中栏展示内容，右栏辅助当前页面。顶栏保留唯一完整栏目导航。减少重复入口、独立白框和无实际数据的装饰组件，同时保留个人空间气质。

本设计覆盖公开页面的侧栏、阅读上下文、音乐入口和搜索布局；不改后台，不更换 Banner 素材，不增加标签云、独立大日历或虚构状态。访问统计暂不实现，只有真实统计来源确认后才能展示。

基线：`fix/single-site-deployment`，`4f96e9a`，开始时工作区及暂存区干净。实现前保留此提交及设计文档提交作为回退依据。不得推送远程，不删除数据库、媒体、备份、目录或批量文件。

## 当前代码与问题

- `PublicLayout.svelte` 负责公共外壳，当前只给 `ContextSidebar` 传入 kind，未传入详情数据。
- `ContextSidebar.svelte` 无条件渲染课表，导致各页上下文雷同。内外两层侧栏均存在左边框和内边距。
- `Detail.svelte` 已有系列、同类前后篇及相关内容，不能再在侧栏照抄一份。
- `MusicPlayer.svelte` 已有浮动播放面板；新增侧栏入口必须共用同一个音频实例。
- 公共列表、详情、系列和标签服务端查询已存在；搜索单独使用公共外壳，需要同样接入上下文协议。

## 布局与视觉

宽屏保留三栏，以左约 200–220px、右约 210–230px、正文自适应为起点，正文不因增加模块进一步变窄。侧栏顶部与正文第一组内容对齐。长侧栏随页面滚动，只有能放进可视区域的目录等短模块使用吸顶，避免侧栏底部无法访问。

左栏为连续个人空间：保留现有个人图片、昵称与简介，用统一轻微主题色底承接个人信息。图片之后是状态、社交图标和音乐摘要，以留白和最多一条轻分隔线区分。不要给每个区域再套卡片。

右栏最多三个主要分组，以小标题、行距、细竖线或短色线建立层级。取消双重边界。颜色来自现有全局语义变量，兼容连续主题色、深浅色和全局字号。悬停只改变文字、轻底色或细色线，不出现深色矩形框，不堆叠右上箭头。

## 左栏内容

1. 身份：复用站点名称、简介和现有图片配置。
2. 当前状态：仅使用明确配置的真实短句及更新时间；没有配置时整段省略。不推断用户正在学习什么，不生成“在线”等状态。状态只在左栏出现，首页右栏不再重复“今日状态”。
3. 链接：关于、RSS，以及已有且有效的社交地址；未配置的社交平台不显示。图标有可访问名称和提示文字。
4. 音乐摘要：封面、歌曲名、播放状态及展开入口；不增加第二套音频、播放列表或控制状态。

## 右栏页面映射

| 页面 | 内容与顺序 |
| --- | --- |
| 首页 | 本周课表；最多三条真实最近更新，优先排除正文已展示项目，去重后无条目则省略 |
| 文章、笔记详情 | 正文目录与阅读进度；系列信息及相邻篇目；最多三条相关内容 |
| 文章、笔记列表 | 当前栏目数量、实际标签筛选；公开系列入口，最多三项；笔记可展示有真实时间依据的最近更新 |
| 系列列表 | 公开系列数量和已应用条件，不复制中间系列列表 |
| 系列详情 | 系列说明、总篇数及当前页信息；具体前后篇只出现在内容详情 |
| 作品列表 | 根据真实项目状态汇总的小型状态分布，不展示某个项目的技术栈 |
| 作品详情 | 当前作品状态、有效技术栈与更新时间；正文存在分节时展示目录 |
| 资源、工具列表 | 类型摘要、有效筛选条件和公开数量 |
| 资源、工具详情 | 来源或可用状态、有效操作入口；正文目录。详情主操作与侧栏摘要不重复按钮 |
| 动态列表及详情 | 真实日期信息、相关主题；长正文才显示目录，不强行补足模块 |
| 标签列表及详情 | 标签数量或选中主题说明、匹配数量，不复制完整标签云 |
| 最近更新 | 真实更新范围与数量，不再展示另一份最近更新列表 |
| 关于、隐私 | 已公开站点信息；关于页可展示有效联系方式；长说明页可展示目录 |
| 搜索 | 筛选归搜索正文内部左侧，结果在右侧；取消额外全站右栏，避免出现两组筛选 |

没有有效上下文时不显示空框或泛泛提示；内容区使用释放的空间。所有链接通过统一公开路径辅助函数生成，只查询当前已公开版本，不使用草稿或工作区数据。

## 数据和组件职责

- 增加客户端可用的上下文类型和纯数据适配器，以页面种类区分首页、列表、详情、集合、搜索和静态页；可选字段缺失时返回空模块，不使用 `any`。
- 服务端页面 load 继续负责公开内容查询。适配器使用现有 `item`、`navigation`、列表统计、集合数据和首页更新数据；需要额外统计时由服务端提供，不从当前分页条目推算全站数量。
- 公共布局从当前页面数据取得上下文并传给右栏，不在布局内发起重复查询；路由变化时派生上下文同步更新，不能残留上一篇文章的信息。
- 个人空间独立为组件，接收身份及可选状态、链接，避免继续扩大公共布局文件。
- `ContextSidebar` 只负责分组展示和响应式入口；课表继续使用 `ScheduleWidget`，仅首页挂载。
- 阅读上下文组件从已渲染且已净化的正文提取 h2/h3，使用稳定且唯一的锚点。目录生成不重新注入原始 HTML，不读取全页面导航标题。
- 播放控制器在当前公共外壳内仅有一个实例，侧栏音乐摘要和浮动入口共享状态及展开动作。不得在服务端创建跨请求共享的用户播放状态。

## 阅读和音乐交互

目录点击定位时扣除顶栏高度，当前章节以主题色短线及文字强调；键盘焦点清晰。阅读进度根据正文开始到正文结束计算并限制在 0–100%，不计 Banner、评论和页脚。短于视口的正文不展示误导性百分比。无 h2/h3 时省略目录。

系列导航优先于普通前后篇，并按内容 ID 去重。宽屏侧栏承担辅助导航后，正文不再展示相同整组模块；移动端将同一组数据移到正文底部。评论仍在正文底部。

音乐不自动播放。点击侧栏摘要或浮动按钮打开同一个面板；浮动按钮在侧栏音乐摘要可见时隐藏，摘要不可见或移动端时显示。切换公共页面不得创建重叠音轨；现有搜索独立布局需要确保导航过程中也只有一个播放器实例。网络失败在播放器内提供重试，不阻塞正文。

## 课表与搜索

课表复用已导入的 WakeUp 数据及上海时区，日期带与课程时间轴作为一个模块；只显示课程名称、日期和时间，不公开教师、地点或原始 ICS。无课显示简短空态，保留上周、本周和下周切换。

搜索保留现有 URL 查询参数及服务端搜索。宽屏正文内部为窄筛选栏加宽结果区，结果区两列；中等宽度根据实际剩余空间降为一列，手机筛选折叠到结果上方。加载失败、无结果、无关键词分别有真实状态，不用推荐假数据填充。

## 响应式与可访问性

- 1100px 及以上：三栏；搜索为个人栏加搜索主区。
- 761–1099px：保留个人栏；右栏的目录在正文开头折叠显示，辅助链接在正文末尾显示。首页课表以正文上方的“本周课程”折叠入口呈现。
- 760px 及以下：单栏；个人资料用紧凑可展开入口，目录及课表使用正文上方折叠入口，音乐使用浮动入口，相关内容置于正文末尾。
- 不同时出现两组相同且可聚焦的控件。展开按钮提供名称与展开状态，浮层支持 Escape 与关闭后焦点返回。
- 验证大字号、长标题及横竖屏，无横向溢出；减少动态偏好下关闭位移动效。颜色和字号变化不破坏触控目标和文字对比。

## 验收与交付

实现分为个人空间、页面数据适配、阅读上下文、音乐共享入口、搜索与移动端五组工作。每组都要使用真实页面检查，不能仅以首页验收。

验证包含：上下文映射和空值回退；公开数据边界；系列和相关条目去重；重复标题锚点；路由切换后目录和播放实例不残留；首页以外无课表；搜索筛选和分页保持 URL 一致。

浏览器检查至少覆盖首页、列表、长正文详情、作品详情、系列、搜索和关于，在 1440px、1024px、390px 下检查布局；覆盖浅色、深色、黄色主题、大字号、键盘操作和减少动态。无数据场景同样验证，不创建公开占位内容。

运行仓库保留式验证脚本前检查其删除行为，遵守文件删除限制。实现完成后审查差异、执行相关检查、明确暂存并提交；保留旧镜像，使用 compose 的 web build 和不清理孤立资源的 up 更新本地服务。最终在 `http://127.0.0.1:5181/` 验证实际部署结果，不推送远程。
