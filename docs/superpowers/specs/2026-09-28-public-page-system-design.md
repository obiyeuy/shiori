# 公开站场景与栏目设计规格

## 已确认目标与范围

本轮将公开站从统一列表模板调整为统一场景框架下的多种栏目排版。首页保留大 banner，所有公开内页使用窄 banner。导航居中、图标统一、设置集中在面板中；栏目不再堆叠巨大标题和重复箭头。用户已确认这个方向。

覆盖：首页、更新、文章、笔记、动态、作品、工具、资源、标签及标签内容、系列及系列内容、关于、隐私、搜索和公开内容详情。登录和管理工作台不纳入此次公开站布局变更，不改变认证、数据库结构、媒体与发布行为。

## 场景与公共框架

- 首页场景高度为 60–65vh，桌面限制在 480–680px；手机为 400–500px。
- 栏目、索引、关于、隐私和搜索页场景为桌面 260px、手机 200px；详情页为桌面 220px、手机 180px。
- 统一使用站点配置的场景图与焦点；默认素材使用现有八奈见杏菜素材的无白边裁切，原文件保留。内页只缩短高度，不新增不同风格的占位插画。
- 首页显示站名和简短欢迎语；内页仅显示小型栏目名及当前位置。详情正文头部承担内容标题、日期、摘要，不在 banner 再复制一遍标题。
- 波浪最多保留两层，分别使用不同曲率、垂直基线与起始相位；色彩与正文画布完全一致。慢速连续平移，无缩放入场。正文在场景结束后保留 16–24px 距离，不用负外边距遮住波浪。
- 居中图标导航：场景上透明，离开场景后纯色。切换阈值依据实际 banner 高度，不固定为 320px。无磨砂。
- 全站框架在宽屏为左侧个人空间、中间内容、右侧上下文工具；中屏收起右栏，手机收起两侧栏。列宽受可用空间约束，禁止页面横向溢出。
- 右栏不再展示伪统计或用当天日期冒充最后更新。无真实数据的装饰模块移除其渲染，源文件和资料不删除。

## 栏目内容模型

| 页面 | 内容组织 | 标题与控件 |
| --- | --- | --- |
| 首页/更新 | 紧凑内容流，首页另有精选与作品分区 | 小型分区标题和栏目切换 |
| 文章 | 日期分组的文章档案，真实封面按需展示 | 紧凑筛选条，不新增巨大介绍卡 |
| 笔记 | 桌面两列短条目，手机单列；标题、摘要、标签和更新时间 | 主题筛选和数量 |
| 动态 | 时间轴与短正文，真实媒体随条目呈现 | 日期组织，不用文章摘要卡伪装动态 |
| 作品 | 真实封面展陈，状态靠近标题；缺封面用文字布局 | 不生成巨大首字占位封面 |
| 工具/资源 | 功能目录，简短说明、真实状态与访问操作 | 仅外链或打开工具使用外链图标 |
| 标签 | 标签及实际数量索引，点击进入对应内容 | 紧凑标题和筛选反馈 |
| 系列 | 按系列组织阅读入口，显示实际数量 | 系列内部体现阅读顺序 |
| 关于/隐私 | 叙事或文档排版，保持阅读宽度 | 不添加虚构个人经历、联系方式 |
| 内容详情 | 内容标题、元信息、摘要、正文、现有相关导航与评论 | 标题服务阅读，不重复栏目大标题 |

普通站内导航及列表取消逐项圆形右上箭头。标题与合理的行点击区域可访问，hover 使用颜色和细下划线；禁止嵌套链接或依赖 hover 才能操作。

## 搜索

搜索也使用窄 banner 与同一导航主题。桌面中间工作区为条件栏与结果栏：搜索框跨越工作区，左侧紧凑类型/标签条件，右侧结果列表；不足以容纳两列时条件折叠到顶部。右侧站点工具按空间收起，避免条件栏把结果挤窄。

沿用现有 GET 参数、查询语义、分页和安全处理。无关键词时展示已有标签和栏目入口；只有查询接口实际提供的数据才显示最近内容或数量，不编造热门数据。结果标题、匹配摘要与类型日期形成清晰层次；加载失败、零结果、超页和清除筛选均有明确反馈。

## 组件和数据职责

- 公共布局统一解析页面场景类型、身份、导航、背景设置与响应式网格；搜索不维护第二份壳层规则。
- 场景组件接收首页/栏目/详情模式、图像、焦点和简短栏目标签，仅负责场景及底部过渡。
- 列表容器保留筛选、分页与 SEO；文章、笔记、动态、作品、目录采用独立展示组件，避免继续向一个展示模板叠加分支。
- 详情阅读组件保留 Markdown、封面、评论与内容行为。
- 所有新增字段来自现有公开查询；确需补充时只扩展公开读取，保持发布权限过滤，不迁移数据库。

## 设置、失败与可访问性

主题仅在显示面板中提供系统/浅色/深色三项。场景开关明确命名为全站场景，关闭后所有公开页面切换到纯色阅读并取消场景占位；纹理与场景可独立控制，避免一个开关多种模糊语义。状态跨刷新与站内导航保持，存储不可用时当前页面仍可操作。

设置面板支持鼠标离开延迟收回、点击外部、Escape；键盘焦点仍在面板内时不因鼠标移出关闭。更多菜单同样支持鼠标和键盘。系统减少动效和用户减少动效任一开启时，波浪与过渡均静止。

图像失败显示稳定的主题底色，标题和内容仍可读；保持素材来源署名，不将设计调研名称放入产品文案。无数据展示真实空状态，不添加占位卡填满页面。

## 验收与交付

1. 实际测量首页、栏目、搜索和详情的场景宽高，确认 x=0、宽度等于视口，无白边、无正文重叠。
2. 在 1440、1280、1024、390px 下检查全部公开路由；检查深浅主题、空列表及有内容详情。
3. 记录波浪在两个时刻的位置，确认运动与层次；减少动效时确认停止。截图审查视觉，不以动画元素存在代替验收。
4. 检查菜单进入、移出、键盘退出、设置恢复、背景切换、搜索提交和分页，控制台无新错误。
5. 使用保留输出的检查与构建流程；运行 lint、相关单元测试和浏览器回归。发现问题修改后复测受影响项。
6. 延续 fix/single-site-deployment；保留现有回退提交。提交前检查实际差异和未跟踪内容，仅提交本任务文件。
7. 部署到 127.0.0.1:5181 并检查运行版本与健康状态。不推送。禁止清理目录、镜像、数据卷、数据库、媒体与备份；不运行附带删除的部署脚本，选择保留旧产物的更新方式。

本规格记录已确认方向与实施约束；视觉验收以真实部署页面为准，不因构建通过而宣称设计没有问题。
