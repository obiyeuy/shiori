# P1 内容生产链验证报告

范围：P1；分支 `feature/p1-content-pipeline`，基线 `ca208dd`。P0 已完成，本阶段没有启动 P2–P5。

## 交付

- 服务端 Markdown 统一管线：CommonMark/GFM、表格、任务列表、脚注、KaTeX、Shiki；raw HTML/MDX/iframe 不执行，危险链接清理，外部图片不下载；Mermaid 严格渲染，单块失败保留源码和提示。
- 媒体暂存、magic bytes、图片/PDF/视频大小限制、40MP 限制、随机键、受保护原图、展示图派生、容量阈值、私有 no-store 和公开 variant 路由。媒体 ready 与 public_at 分离，失败重试不删除文件。
- CodeMirror 响应式编辑器、2 秒空闲/15 秒最长自动保存、CAS 冲突、检查点、不可变版本、完整字段恢复、导入/导出、媒体插入、窄屏编辑/预览标签。
- 发布前字段/slug/标签/媒体 preflight、幂等操作键、固定版本排期、默认取消旧排期、撤回原子取消、公开投影/RSS 稳定 ID/历史 alias/审计事件、受控 worker 和 1/5/15 分钟退避。
- 增量 SQL 迁移、Docker media bind mount 和可选 schedule-worker profile。

## 验证结果

- `pnpm test`：21 个测试文件，64 项通过；实际 PostgreSQL schema，发布/排期故障注入和并发竞态使用真实数据库。
- `pnpm typecheck`：0 errors / 0 warnings。
- `pnpm lint`：通过。
- `pnpm build`：通过，Node adapter 产物生成。
- 浏览器：安装的 Chrome，真实登录、CodeMirror 保存、Mermaid 成功/单块失败回退、320px 无横向溢出、编辑/预览切换、双标签冲突、发布响应丢失后查询操作结果；截图保留于 `.superpowers/sdd/个人综合站-实施计划-P1-内容生产链/`。
- 依赖审计：0 high / 0 critical，1 moderate，1 low。Mermaid 间接 `lodash-es` 已覆盖到 4.18.1；moderate 为 Drizzle Kit 的开发服务器 esbuild，生产不运行 Drizzle dev server；low 为 SvelteKit 间接 cookie 校验，站点使用受限 cookie 名称与固定 path。
- 本机实际 `statfs` 可用比例约 9.9%，所以生产逻辑确实停止新增媒体；成功路径仅在测试内模拟充足容量采样，仍执行真实 sharp、文件系统和 PostgreSQL。

## 运行边界

- `MEDIA_ROOT` 不能放在静态目录，默认 Compose 容器内 `/data/media`；宿主 `MEDIA_ROOT_PATH` 需管理员预先准备并设置权限 0700。P1 不启动或替换现有容器。
- `pnpm worker:schedules` 每 30 秒扫描，`--once` 单轮；生产建议通过 Compose `pipeline` profile 单独运行。迁移仍由显式 `pnpm db:migrate` 执行，Web 启动不迁移。
- 生产服务器需要 HTTPS、真实媒体目录、备份策略、容量采集、OAuth/Giscus 输入；本阶段未部署、不创建外部资源。

## 遗留限制

- P1 没有公开详情、搜索、RSS 页面；这些由 P2 消费公开投影。
- P3 负责工作台列表、媒体列表、排期列表和共享工作台布局；本阶段没有创建这些文件。
- P4 负责服务器部署、备份和恢复演练；P5 负责全站性能、读屏/IME、完整上线门禁。
- 目标字体、正式 Banner/作品素材、真实 GitHub OAuth 仍待后续输入与验收。

审查范围补充：P1 独立审查任务因使用额度限制未返回结论；既有验证记录为实现者自查与实际测试证据，不代表独立审查通过。
