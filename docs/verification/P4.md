# P4 备份与隔离恢复验证

分支 feature/p4-backup-recovery，基线 6c74404。已实现签名加密备份集、同快照应用逻辑转储/全部媒体清单、只读 SSH 拉取、幂等 Mac 回执、只读状态、独立评论导出、容量采集、隔离恢复及独立生产 Compose 模板。
