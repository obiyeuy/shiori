## 独立审查与回归

只读审查者检查了源代码、规格及验证日志，没有修改文件或数据库。发现并修复：

1. 原始 URL 与 SvelteKit 解码后路由不同导致鉴权绕过。回归 `/%77orkspace` 从 200 变为 303，编码认证路径也受 Origin 校验。
2. 未知 JSON 字段进入稿件。采用按类型允许字段集，保留“不完整稿可保存”规则。
3. PostgreSQL `now()` 为事务开始时间，旧请求等锁后误判新更新时间为未来。真实并发测试先失败，改用 `clock_timestamp()` 和单调更新后通过。
4. 提前抛出拒绝/重定向时遗漏 `no-store`。实际 HTTP 断言先失败，显式构造带私有响应头的拒绝响应，并统一包装已解析的私有响应。

以上均有失败→修复→全量通过记录；未留已知 Important/Critical 审查项。
