# 上线门禁

状态：**暂不允许上线**。这是验收结果，不是待授权的自动部署；用户将在服务器自行部署。

已具备：本机核心测试、公开搜索/权限隔离、生产构建、独立部署模板、加密签名备份与本机隔离恢复。对应证据见 [追踪矩阵](../acceptance/traceability.md)。

上线前必须完成：

- 真实服务器只读检查：磁盘余量、端口/网络/卷、现有服务占用；独立项目不覆盖现有容器。
- 真实域名、TLS、Cloudflare/反向代理，验证 Origin、Secure Cookie 和私有 no-store。
- 唯一站长初始化、强密码和独立会话密钥；GitHub OAuth 如启用，核验 numeric ID/回调/绑定/重新认证。没有创建外部 OAuth 应用。
- 站名/定位/公开链接/隐私内容、首批内容工具、真实服务地址；Banner/作品素材授权与目标字体实测。
- 真实 Giscus 配置及第三方加载/失败、Discussion 对应；评论备份 API 权限及全分页导出。
- 专用备份/回执 SSH 账号、最小权限、密钥独立加密副本、调度时段、完整 Mac 拉取校验/补发；确认最新恢复点不超过26小时。
- 在目标机器以代表性数据做完整恢复，核对未引用/历史媒体、配置、旧会话和排期隔离；大数据先解决当前内存式备份容量限制。
- 真实辅助技术读屏、中文 IME、200%浏览器缩放、全部关键路径键盘/焦点；自动 DOM 检查不能替代。
- 代表性移动硬件及真实素材下测量 LCP≤2.5s、CLS≤0.1、INP≤200ms；本机节流数据只作实验，不充当真实用户分位数。
- 配置容量与任务状态采集、日志接收和容量告警。禁止自动批量删除/轮转清理；积累产物需人工治理。

任一完整性、安全、恢复失败保留失败证据与最后可信恢复点，修复后重测，不绕过门禁。未推送、合并或部署。当前容器仍为旧 P0 镜像，不能据旧容器画面判断已提交的新产品。
