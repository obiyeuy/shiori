# 当前跨页基线

状态：当前设计基线。正式规格已审阅通过；工程实现和运行验收状态见 `docs/verification/`。本文件优先于 MASTER 的历史自动生成规则及页面文件中的早期矛盾。

- 延续首页综合 v2：大幅日系场景、一次主面板重叠、开放式内容区；无固定角色、复古装饰、随机旋转、鼠标特效。
- 色彩：暖白 #FBF9F7 / 深紫灰 #171522，主色 #6D5CE7，辅助粉 #E879A9、黄 #E7B94E、蓝 #63A9D8。亮色用作背景/强调，不能假定直接作小字即合格；最终逐组合验证对比度。深色正文与按钮另设语义色，不反转图片。
- 字体：Noto Sans SC 中文，Space Grotesk 少量英文数字，JetBrains Mono 代码。字体 swap，界面正文字号 16px 起。
- banner 高度由断点约束，容器提前预留空间；图像 object-fit 裁切，不要求桌面与手机使用同一个固定宽高比。可设置独立手机图和焦点。
- 桌面 ≥1100px，平板 768–1099px，手机 <768px；长站名或字体放大导致导航不足时提前收纳，不硬挤溢出。公开首页顺序不变。
- hover 为颜色/背景/边界/箭头反馈，不抬升或旋转内容块；reduced-motion 禁用进入位移和淡入。
- 图片有意义时提供描述，装饰图空 alt；失败用容器文本替代，不能只写一个不可见 alt 声称已有失败体验。
- 搜索为独立页，Escape 不退出页面；菜单/主题选择等真正弹层才关闭并归还焦点。
- 外部服务仅链接，不因按需加载规则引入 iframe 或探测；Giscus 仅在支持评论的详情页按需加载。
- 内容 URL、标签与系列使用真实链接；精选与更新可共享摘要，分页各自 canonical，搜索及组合筛选 noindex。
- 公开详情与编辑预览共享渲染规则，工作台侧栏仅显示首版真实功能；Giscus 待审核数和服务在线状态不虚构。
- 作品与工具是独立区域；相册后置。首页全量设计稿需包含 6 条更新、3 篇精选及最多 3 件作品/工具，不能用早期缩略草图代替最终验收。
