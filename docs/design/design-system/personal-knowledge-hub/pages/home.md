# 首页视觉覆盖：二次元活泼内容站

本页覆盖 MASTER.md 中偏极简、粗野主义的默认方向。产品仍保持内容可读性，但加入轻量二次元和创作者气质。

## 方向

- 架构：A＋C。公开首页使用内容优先的顶部导航；登录后进入独立的个人空间。
- 风格：轻二次元、活泼、明快、有角色感，但不做儿童化卡通，也不使用大面积装饰压过文章内容。
- 视觉语汇：圆角卡片、彩色标签、少量徽章、明确的编辑版式、细线描边、柔和阴影和现代场景插画；不把贴纸或角色作为必备组件。
- 不使用复古网页式星星、网点、波纹等装饰。视觉识别依靠角色构图、色块、贴纸标签和局部插画；装饰只放在首页欢迎区、空状态、工具卡片和交互反馈中，文章正文保持安静。

## 色彩

```css
--color-bg: #FFF9F5;
--color-surface: #FFFFFF;
--color-ink: #24213A;
--color-muted: #6B6780;
--color-primary: #6D4AFF;      /* 紫 */
--color-secondary: #FF6B9D;    /* 粉 */
--color-accent: #FFC857;       /* 黄 */
--color-info: #62C6FF;         /* 蓝 */
--color-success: #56C596;
--color-border: #E8E1F2;
```

使用 1 个主色、1 个辅助色和 1 个强调色控制视觉层级。亮色只用于按钮、标签、插图和选中状态；正文仍使用深色文字，保证对比度。

## 字体

- 中文标题与导航：Noto Sans SC 600–800。
- 英文或短标题：Space Grotesk 500–700，少量使用，不用于长正文。
- 正文：Noto Sans SC 400–500，16px 起，行高 1.7。
- 代码与技术标签：JetBrains Mono。

## 首页结构

### 已确认的布局骨架

- 采用方案 01：顺序分区，局部加入不对称卡片和角色装饰，不采用全页卡片拼接。
- 电脑与手机都适配，同一网站根据可用宽度调整布局；主要内容阅读顺序保持一致。
- 具体断点、列数、导航收纳、角色身份、造型与视觉强度尚待细化，不将占位草图视为定稿。
- 二次元强度采用现代场景插画方向，不使用复古星星、网点、波纹等装饰；首版不固定角色。
- 场景插画融入首页横向欢迎 banner，不作为独立 Q 版贴图；欢迎语置于场景留白处，下方内容区保持白色主面板和稳定阅读节奏。可借鉴 Fuwari 的舒适感，但不复制其素材或页面结构。
- Fuwari 综合参考规则（待用户确认）：大幅可配置 banner（含焦点位置和署名）、轻量悬浮圆角导航、单一 hue 主题色、banner 下方仅一次主面板重叠、稳定编辑网格和开放式文章流。角色进入场景而非单独贴图；正式站点使用自有或已获授权插画。移动端缩短 banner、主面板单列、保留同一阅读顺序。
- 综合方案草图（待确认）：桌面端大幅场景 banner 约占首屏 40–48%，导航轻量悬浮；banner 下方只做一次白色主面板重叠；主面板采用 12 列编辑网格，个人简介与最近更新形成稳定两列关系；精选、作品、工具用开放式分栏和分隔线组织，减少小卡片。移动端缩短 banner、主面板单列、更新条目纵向排列；已确认的栏目顺序和展示数量保持不变。
- 扩展参考调研后的综合规则（待确认）：采用现代 Material 组件基础、日系场景 banner、个人小窝信息架构和安静文章流的组合。可以有个人资料、笔记、相册/友链等后续栏目入口，但首页只展示已确认的内容区；不采用樱花特效、鼠标特效、音乐播放器或统计组件堆叠。综合草图 v2 使用临时参考 banner，正式实现替换为自有或获授权插画。
- 综合方案 v2 已获用户确认作为首页基础方向；后续只做细节优化。待细化项目包括 banner 构图与焦点、角色出现方式、桌面/移动断点、组件状态和交互。
- 角色策略已确认：首版不使用固定吉祥物或固定角色，采用可替换的场景插画系统。人物可出现在 banner 或内容配图中，不作为全站品牌锚点；空状态和工具页不重复贴角色。
- 首页 banner 已确认使用一张稳定主图，不随机轮换；后台可替换图片、设置焦点位置并记录作者/来源署名。响应式按焦点裁切并预留固定比例；无图片时用同尺寸纯色或柔和渐变占位。文章详情页使用独立封面。
- 响应式已确认：桌面 ≥1100px 完整导航、banner 约 400–460px、主面板重叠约 32px、个人介绍可三列；平板 768–1099px 收窄导航与 banner、个人介绍两列；手机 <768px 导航折叠、banner 约 250–320px、主面板重叠约 20px、内容单列。阅读顺序保持一致。

1. 顶部导航：内容优先；公开栏目包含首页、文章、笔记、动态、作品、工具、资源、关于。搜索、主题切换和个人空间入口的具体排列待确认。
2. 简短欢迎区：一句定位与头像／角色视觉位置，不放长篇自我介绍。
3. 最近更新：已确认采用文章、笔记、动态混合列表，按时间穿插，使用文字类型标签区分，不仅依靠颜色。作品和工具不进入该列表，分别在下方独立展示。按首次公开发布时间排序；普通编辑不会重新置顶，作者可显式标记重要更新后重新进入列表。首页默认展示 6 条，不人为设置动态占比上限，完整列表通过“查看全部”进入。
4. 精选文章／笔记：默认展示 3 篇，由站长手动标记精选，文章和笔记均可入选。可与最近更新重复；没有手动精选时隐藏整个区域，不自动填充。卡片大小关系待确认。
5. 作品：独立展示区，首页最多展示 3 个，由站长手动标记首页展示；卡片包含封面或视觉缩略图、名称、一句话说明和状态标签。没有公开作品时隐藏整个区域，通过“查看全部”进入作品页。
6. 工具：首页最多展示 3 个适合访客使用的公开工具。卡片显示名称、用途、一句话说明和“打开工具”；外部链接明确标记为外部工具，暂不可用时显示状态并避免进入无响应页面。没有公开工具时隐藏整个区域；现有 Docker 服务入口仅出现在站长登录后的个人空间，不进入公开首页。
7. 页脚：分为内容（文章、笔记、动态、作品、资源）、连接（GitHub、RSS、联系方式）、站点（关于、隐私说明、登录个人空间）三组；保留站点名称、版权年份和内容许可说明。移动端纵向排列，不显示服务名称或私人功能信息。

电脑端可用多列卡片、手机端按内容宽度收为单列；这是布局细化建议，具体列数尚未批准。

## 交互

- 内容 hover 使用 150–220ms 的背景、边界或箭头反馈；不抬升、旋转内容块，禁止持续晃动。
- 标签可点击筛选；颜色之外同时显示文字，不能只靠颜色传达类型。
- 插画和装饰默认不参与键盘焦点；图标按钮必须提供 aria-label。
- 尊重 prefers-reduced-motion，减少位移、旋转和渐变动画。
- 断点：375、768、1024、1440px；移动端顶部导航折叠为菜单，个人空间使用抽屉式侧栏。

## 内容页约束

- 文章详情正文仍限制在 65–75ch，避免二次元装饰影响阅读。
- 目录、阅读进度、上一篇/下一篇使用紫色主色；评论区保持白底卡片。
- 图片保留圆角和原图比例，加载前预留 aspect-ratio，避免布局跳动。

## 已确认的首页细节补充

- Banner 素材：有环境的日系场景，人物可选；桌面主体偏右、左侧文字留白。欢迎语使用独立文字，仅文字区域按需加渐变，不整体压暗、模糊或褪色。允许独立手机焦点和同场景手机版本；深色模式保留插画原色，后台同时预览桌面/手机再替换。该规则细化稳定单 banner，不引入轮播。

- 分区版式：精选桌面一主两次、手机按主次单列，站长手动排序、第一篇为主推荐，封面可选；作品每件一行、大图与说明左右分列，手机图上文下；工具为紧凑入口列表，移动端单列。数量不足自然收缩，不补空卡片。
- 精选、作品、工具保持独立分区和既定阅读顺序，靠留白区隔，不旋转、不随机错位、不增加整区边框容器。

- 综合方案 v2 已确认作为基础方向：大幅场景 banner、现代主题组件、个人小窝信息架构和安静文章流；后续只做细节优化。
- 首版不使用固定吉祥物或固定角色，采用可替换的场景插画系统；人物可出现在 banner 或内容配图中，不在空状态和工具页重复贴角色。
- 首页使用一张稳定主 banner，不随机轮换；支持焦点位置、署名和响应式裁切。无图时保留同尺寸渐变占位。
- 响应式：桌面 ≥1100px 完整导航、banner 约 400–460px、主面板重叠约 32px；平板 768–1099px 收窄导航与 banner、个人介绍两列；手机 <768px 导航折叠、banner 约 250–320px、主面板重叠约 20px、内容单列。阅读顺序保持一致。
- 状态与交互：banner 加载/失败保留占位；最近更新默认 6 条，空时显示文字提示；精选、作品、公开工具为空时隐藏；不可用工具保留说明但禁用打开；hover 只做背景/边界/箭头反馈，键盘焦点清晰；标签可点击筛选且显示文字；支持深色主题、reduced-motion 和错误隔离。
- 顶部导航已确认：桌面端内容栏目优先（首页、文章、笔记、动态、作品、工具、资源），右侧放搜索、主题切换、关于和登录个人空间；平板端收纳部分栏目至“更多”；手机端以站点标识、搜索、主题切换、菜单为主，菜单分为内容、展示、站点三组，不使用底部五项导航。
- 主题色已确认：蓝紫作为唯一主色，粉/黄/浅蓝分别承担动态社交、精选状态、笔记信息语义；暖白浅色背景与深紫灰深色背景；深色模式保留主题色但降低大面积饱和度，正文对比度至少 4.5:1。
- 字体与基础形态已确认：Noto Sans SC 负责中文内容，Space Grotesk 用于少量英文/数字，JetBrains Mono 用于代码和技术标签；不使用 Fredoka 做大标题。banner 圆角 24–32px，主面板 24–28px，普通卡片 14–18px，8px 间距网格，正文 16px 起、行高约 1.7，阴影保持轻量。
- 参考综合：Shirone 的现代主题控制、Mizuki 的个人空间栏目感、Fuwari 的文章流、Sakura/Sakurairo 的大图门户氛围；不采用樱花特效、鼠标特效、音乐播放器或统计组件堆叠。
- 首页不承载完整个人空间栏目：关于、资源、友链、相册/作品集和动态详情各自独立；首页只保留个人简介、最近更新、精选、作品和公开工具。
- 媒体：保留原图并按需生成 WebP/AVIF 展示版本；banner 可设置桌面/手机图与焦点、署名和许可。使用响应式尺寸、懒加载、固定宽高比和稳定媒体 URL；失败显示占位与 alt；未使用媒体只提示，不自动删除，临时参考图不进正式站点。
- 动效与性能：交互 150–220ms；不使用持续晃动、自动轮播、鼠标跟随、默认视差或复杂滚动时间线；进入动画仅轻微淡入，重要内容不依赖 JS；reduced-motion 移除位移/缩放/淡入；按设备加载 banner，非首屏图片懒加载并预留尺寸，外部组件按需加载。
- 无障碍：所有导航/按钮/标签/卡片可键盘访问；焦点 2px 外轮廓；类型显示文字而非仅颜色；图片使用合适 alt；菜单/搜索/主题切换支持 Escape 和焦点恢复；触控目标 ≥44px；标题层级连续；关键内容不依赖 hover；代码、表格和外部链接保留语义。
- 内容与 SEO：首页只有一个 h1，分区连续使用 h2、内容标题从 h3；卡片使用真实链接；精选可与更新重复但文案不完全重复；首页 description 基于站点定位与近期主题；OG 使用 banner 与站点标题；公开内容进入 RSS，草稿/私有内容/服务入口不进入公开搜索、RSS 或站点地图；标签/系列可索引且筛选参数不制造重复页面；URL 稳定；Giscus 不阻塞正文。
- 首页验收基线：大幅场景 banner、清晰欢迎语和内容优先导航必须在首屏成立；只做一次主面板重叠；阅读顺序在桌面/平板/手机一致且无横向滚动；不使用固定吉祥物、复古特效或随机错位；空/失败/reduced-motion 状态可读；正文和辅助文字满足对比度与键盘操作；首屏内容不被图片、字体或第三方组件阻塞。
- 内容/SEO：首页单一 h1，分区 h2、卡片 h3；内容使用真实链接；精选可与更新重复但文案区分；Open Graph 使用 banner；草稿、私人内容和站长服务不进入 RSS、站点地图或公开搜索；作品和工具有独立页面；canonical 与公开 URL 稳定；Giscus 不阻塞正文。
