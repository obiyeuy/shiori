# 编辑器与发布工作区

状态：用户授权按推荐连续记录的设计基线，尚非实施批准。对应《个人综合站-架构与交互设计草案》第 3–6 节。

- 桌面源码/预览并排，窄屏编辑/预览切换；切换不丢正文、选区与滚动位置。可收起设置进入专注编辑。
- 顶部：标题、保存状态、预览、保存版本、发布。设置区：摘要、封面、标签、slug、评论开关；系列显示归属和管理入口，关系在系列管理页显式保存；手机用独立设置面板。
- 工具栏插入 Markdown；图片支持粘贴/拖入/选择，显示上传进度、失败与重试，上传未完成不能发布。
- 自动保存仅写编辑稿。状态区分未保存、保存中、已保存时间、离线、失败、会话过期和修订冲突；不能以动画代替真实保存状态。
- 发布面板明确版本、URL、时间和变化；立即发布/排期分别标注。继续编辑不改变排期版本，更新排期需要显式操作。
- 版本历史显示来源和字段差异，恢复生成新稿，不覆盖线上或排期。
- 草稿预览与草稿媒体均鉴权，no-store；预览共享公开渲染规则，渲染失败局部展示错误。
- 无网络/会话过期时保留内存内容并支持导出；不默认将私有正文长期写入 localStorage。多标签页冲突保留两份供比较，不静默覆盖。
- 首版不提供批量删除、目录清理或自动媒体清理。

- 已采纳的审阅补充：有排期时手动发布默认取消，可显式保留；按钮文案显示实际后果。slug 修改只在发布时改变公开地址。展示图与原图分别授权，原图默认受保护；发布面板显示本次公开文件范围。
- 功能分册补充：草稿允许字段不完整，必填检查作用于发布/排期；发布使用服务端已确认修订。响应丢失显示结果待确认，先查询操作结果，不盲目重复发布。
