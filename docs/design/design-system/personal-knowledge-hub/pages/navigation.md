# 导航与公开路由信息架构

## 公开站

- `/`：首页
- `/articles`：文章列表
- `/notes`：笔记列表
- `/moments`：动态时间线
- `/projects`：作品列表与详情
- `/tools`：公开工具列表与入口
- `/resources`：资源列表
- `/about`：关于、联系方式、站点说明，可包含友链区块
- `/search`：独立搜索页
- `/tags/[slug]`、`/series/[slug]`：标签与系列页
- `/rss.xml`、`/sitemap.xml`：公开内容分发

## 首页内容边界

首页只负责入口和摘要：最近更新 6 条、精选 3 篇、作品最多 3 个、公开工具最多 3 个。关于、资源、友链、相册/作品集和动态详情不在首页展开。

## SEO 与内容边界

- 公开页面使用稳定 canonical URL；筛选和分页参数不生成重复索引。
- 草稿、私人内容和站长服务入口不进入公开 HTML、搜索、RSS 或站点地图。
- 首页只有一个 h1；分区使用 h2；内容标题从 h3 开始。
- Giscus 按需加载，不阻塞正文或首页首屏。
