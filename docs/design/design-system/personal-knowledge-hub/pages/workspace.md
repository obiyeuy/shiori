# 个人空间视觉覆盖

- 与公开站共享色彩、字体和组件，但背景改为淡紫灰 `#F7F5FF`，突出工作台层次。
- 桌面端使用约 240px 侧栏：概览、内容（含草稿/标签/系列）、媒体、排期、评论设置、服务入口、站点设置、账号安全；后置私人功能不显示空入口。
- 侧栏选中项使用紫色胶囊背景和短文字状态标记；不使用星形、网点等复古装饰，也不使用仅图标导航。
- 内容管理列表保持高密度，但操作按钮仍满足 44px 点击区域。
- 保存和排期状态使用文字徽章；保存成功/失败等操作结果使用适度 aria-live 提示，静态列表不逐项播报。
- 移动端侧栏变为抽屉，顶部保留当前页面标题和返回按钮。
- 概览首先显示保存/排期异常、容量与备份提醒，再显示最近草稿、未来 24 小时排期、服务快捷入口；带数据时间，未知不显示正常。无事项用简短状态，不用大型插画填充。
- 评论设置连接 GitHub Discussions 管理，不虚构本站待审核/未读队列；没有额外 API 集成就不显示对应计数。
- 服务卡片显示名称、说明、URL、手动状态与打开按钮；默认“未检测”。首版不自动探测、不嵌 iframe、不获取 Docker socket，不改变现有服务认证。
- 内容列表每页 20 项，可筛选类型、标签、公开/草稿/排期状态；“已发布、有未发布修改、有排期”可同时成立。空列表提供创建入口，查询失败保留条件并重试。
- 移动端抽屉支持焦点约束、Escape 关闭、焦点回到触发按钮和滚动恢复；表格改成条目展示，操作触控区不少于 44px。
- 登录页同时提供账号密码和 GitHub 登录，明确这是站长入口而不是注册页；失败信息不暴露账号是否存在，密码输入支持显示/隐藏但默认不回显。登录成功回到原受保护路径，取消或失败不丢失公开页面上下文。
- 账号安全页显示当前会话、GitHub 绑定状态、最近安全事件和恢复命令说明；修改密码、绑定/解绑 GitHub、撤销其他会话要求再次验证。不能解绑最后一个可用认证方式。
- 服务入口卡片采用“用途优先”文案，状态区分未检测、站长标记可用、站长标记维护和站长报告不可用；人工状态带更新时间。不根据外链打开推断健康或失败；不自动探测目标、不内嵌 iframe，外链按钮使用 `rel`/安全 URL 策略。
- 内容归档仅改变后台收纳，公开状态不变；已归档内容的排期和异常仍在概览及排期页显示。停止公开使用撤回。
- 运行状态以《个人综合站-功能与状态规格》第 4 节为准：本机备份与 Mac 回执分开，恢复点使用备份集数据库快照时间；无记录、陈旧、读取失败不显示正常。保留最近成功时间并同时显示最近失败。
