# 搜索页设计规则

状态：交互方案已确认，具体视觉细节待完整设计审阅。

- 使用独立搜索页，沿用公开站导航与主题。导航搜索入口进入后聚焦输入框，回车提交。
- 搜索词、类型和标签保存在 URL，支持分享、刷新和后退；从详情返回恢复查询、筛选和列表位置。
- 结果显示内容类型、标题、命中片段并适度高亮命中词。仅搜索已发布公开内容，私有内容不进入结果或计数。
- 桌面筛选放在结果上方；手机折叠筛选，已选条件保持可见。
- 未输入时提示可搜索的内容范围；无结果时保留输入与条件，提供换词和清除筛选提示。
- 加载失败时保留输入、提供重试，不误报无结果。每页 20 项真实分页链接；更改查询或过滤回到第 1 页，加载反馈保留布局及焦点。
- 功能分册补充：空白分片段 AND、同组类型/标签 OR、不同条件组 AND；保留 C++/C#/Node.js 等符号语义。结果、计数与片段仅来自当前公开版本。16 组样例和具体排序见《个人综合站-功能与状态规格》第 3 节，尚未执行实现测试。
