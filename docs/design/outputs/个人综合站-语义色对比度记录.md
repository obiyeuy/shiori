日期：2026-09-25。范围：纯色、不透明前景与背景的 WCAG 相对亮度计算；不是浏览器截图、插画叠字、完整无障碍或最终视觉验收。

计算：sRGB 通道除以 255；通道值不大于 0.04045 时除以 12.92，否则 ((值 + 0.055) / 1.055)^2.4；相对亮度为 0.2126R + 0.7152G + 0.0722B；比值为 (较亮亮度 + 0.05) / (较暗亮度 + 0.05)。先以原精度判定，再保留两位小数展示。
