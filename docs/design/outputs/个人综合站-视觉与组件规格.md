# 个人综合站：视觉与组件规格

日期：2026-09-25。状态：正式规格的视觉分册，推荐细节供完整规格审阅；不是产品代码或最终渲染验收结果。

进度更新：已生成第一批 48 张静态画板，见《个人综合站-静态视觉稿-v1-审阅索引》。本文末尾“待实际视觉稿”指完整最终稿；本批使用无图 Banner 与系统替代字体，部分目视检查已完成，未验证运行时交互或最终素材。

沿用综合方案 v2：现代主题组件、日系场景 Banner、个人小窝的信息架构、安静文章流。没有固定吉祥物，不重新选整体风格。配套《页面线框与状态稿》规定页面结构，《语义色对比度记录》记录计算结果。

## 1. 视觉层级与布局

首页氛围由一张稳定场景图承担，内容区只做一次重叠。卡片用于有独立操作的对象，不为每个段落套容器；文章流以字号、留白、细分隔线分层。蓝紫用于主要操作和当前选中；粉、黄、蓝用于少量语义标签，状态始终同时有文字。

### 1.1 尺寸与断点

| 项目 | 桌面 ≥1100px | 平板 768–1099px | 手机 <768px |
|---|---|---|---|
| 公开站外边距 | 32px，1440 画板主容器两侧 80px | 24px | 16px；320 宽时 12px |
| 主容器 | 最大 1280px，居中 | 可用宽度 | 可用宽度 |
| 导航 | 64px 高起，空间不足提前收纳 | 64px；次要项进“更多” | 64px；站名、搜索、主题、菜单 |
| Banner | 400–460px，1440 基准 440px | 340–400px | 250–320px，375 基准 280px |
| 主面板重叠 | 32px | 24px | 20px |
| 主面板内边距 | 48px | 32px | 20px；320 宽时 16px |
| 分区间距 | 64px | 48px | 40px |
| 分区标题至内容 | 24px | 24px | 20px |
| 列间距 | 24–32px | 24px | 单列，条目间 16–24px |
| 工作台导航 | 240px 固定宽侧栏 | 抽屉 | 抽屉 |

尺寸是设计目标而非固定内容高度：正文放大、长标题和错误信息均可使组件增高。不要以裁剪文字来维持画板高度。首页介绍与最近更新保持先后两个分区；历史“两列简介+更新”草图不再与当前顺序混用。介绍分区内部桌面可三列、平板两列、手机一列。

公开导航默认随页面滚动，首版不增加读者页吸顶遮挡；工作台工具栏可在编辑区域顶部保持可见，锚点与焦点需避让。手机抽屉宽度不超过 360px 且留可见遮罩，320px 时可全宽；所有导航项纵向可滚动。

### 1.2 字体与形态

| 用途 | 桌面 | 手机 | 规则 |
|---|---|---|---|
| 首页欢迎标题 | 40/52px，700 | 28/38px，700 | 通常两行以内；长文案允许增高，不截断 |
| 详情页标题 | 36/48px，700 | 28/38px，700 | 单独 h1，不把封面文字当标题 |
| 分区标题 | 26/36px，600 | 22/32px，600 | 与“查看全部”形成稳定一行或自然换行 |
| 条目标题 | 20/30px，600 | 18/28px，600 | 不强制单行省略 |
| 长文正文 | 18/32px，400 | 17/30px，400 | 中文约 32–40 字一行作为观察目标，非字符硬限制 |
| 界面正文/辅助文案 | 16/26px | 16/26px | 元信息靠颜色/间距弱化，不靠极小字号 |
| 代码 | 15/24px | 15/24px | 独立横向滚动；复制按钮 ≥44px 热区 |

中文 Noto Sans SC；英文站名和少量数字 Space Grotesk；代码 JetBrains Mono。字体缺失时使用系统中文/无衬线/等宽回退，不阻止阅读。以上字重是目标，字体加载策略后续验证，不加载所有字重。

正文容器最大约 720px，目录约 200px，中间 40px；仅当可用宽度容纳时并排。65–75ch 只作拉丁文本参考，不将 ch 当汉字数。表格、公式及代码各自处理溢出，页面本身不横向滚动。

Banner 圆角 28px，主面板 28px，普通卡片 16px，输入/按钮 12px，标签胶囊。间距以 8px 网格为主，4px 用于小组件内部微调。浅色仅使用轻阴影，深色主要靠表面明度和边界，不做发光描边。

## 2. 语义色

品牌原色保持 #6D5CE7、#E879A9、#E7B94E、#63A9D8。组件引用下列用途色，不能直接拿亮粉/亮黄写小字。

| 语义 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| canvas | #FBF9F7 | #171522 | 公开站底色 |
| surface | #FFFFFF | #221E30 | 主面板、输入、弹层 |
| soft | #F1EDF9 | #2D273E | 次级按钮、选中容器、禁用底色 |
| workspace | #F7F5FF | #1B1828 | 工作台底色 |
| text | #272334 | #F5F1FA | 正文、标题 |
| muted | #686174 | #B9AFC9 | 日期、说明、占位文字 |
| border | #827A91 | #8A7E9D | 必要输入/控件边界 |
| line | #E5DFEB | #443A55 | 仅装饰分隔线，不负责唯一可操作辨识 |
| primary | #6D5CE7 | #B5A6FF | 主按钮背景 |
| primary hover | #5D4CCB | #C5B9FF | 指针停留 |
| primary pressed | #503EB3 | #A391F0 | 按下反馈 |
| onPrimary | #FFFFFF | #241A46 | 主按钮文字 |
| link / focus | #5945C5 | #C5B9FF | 正文链接、焦点环 |
| success / background | #24623D / #E6F3EB | #97D7B0 / #1D352A | 保存成功、人工可用标签 |
| warning / background | #79520B / #FFF2D8 | #F0CC83 / #3B2E18 | 维护、容量、记录陈旧 |
| error / background | #A52B47 / #FBE9EC | #FFAAC0 / #3E222D | 保存失败、排期失败 |
| info / background | #245B85 / #E7F1FA | #A4CDED / #1F3042 | 笔记、说明信息 |
| pink / background | #8C365D / #FBEAF2 | #EFACCD / #3C2738 | 动态类型，不充当错误色 |

46 组指定不透明色对已计算通过对应门槛，详见配套记录。普通文字至少 4.5:1、必要控件边界及焦点至少 3:1。即使小字大字都满足计算，也仍需实际字体、缩放和背景图验收。

主题选项为跟随系统、浅色、深色；初次跟随系统，用户选择可保存在仅含主题偏好的本地配置中，不存正文或身份信息。选择与当前生效主题同时清晰可见，避免只用太阳/月亮表示三种状态。首屏避免明显主题闪烁，最终实现验证。

Banner、作品截图和正文图片不反色。欢迎文字使用深色 text 的浅色文字区衬底或白字的深色局部遮罩；具体方案随实际插画明暗选一种，并逐图验证。未经验证时使用足够不透明的局部衬底，不以全图变暗解决。换图操作包括桌面/手机裁切、欢迎文字可读性和署名预览。

## 3. 组件状态矩阵

所有可交互状态叠加可见焦点；加载、按下不能隐藏焦点环。焦点为 2px 外环及 2px 同表面间隔，主按钮边缘与外环之间有清晰间隔。颜色/背景过渡 150–220ms；不让文章块抬升或旋转。

| 组件 | 默认/hover/按下 | 键盘与选中 | 禁用/加载/失败 |
|---|---|---|---|
| 主按钮 | primary + onPrimary；hover/pressed 使用专用色 | 文案明确操作；焦点外环保持 | 禁用用 soft + muted，附不可操作原因；加载保留文案和宽度，如“正在发布…” |
| 次按钮 | surface + text + border；hover 用 soft | 与主按钮相同热区和焦点 | 不降低整个组件透明度；错误动作仍可通过说明理解 |
| 危险动作 | errorBg + error，“撤回公开内容” | 首次点击进入后果确认 | 不放在最醒目的默认主按钮位；不出现删除目录/批量删除 |
| 正文链接 | link，始终下划线 | 焦点环，访问后仍可读 | 不可用目标用文字说明，不伪装可点击链接 |
| 导航/标签筛选 | text 或语义标签；hover 用背景/边界 | 当前页文字加粗/短横线，筛选有勾选或“已选”文字 | 不只变颜色；切换失败保留原条件 |
| 输入框 | surface + text + border，真实可见 label | focus 环；错误时保留环并显示错误标记 | 只读仍可选中复制；错误文案与字段关联，加载不擦除输入 |
| 内容条目 | 开放式标题/摘要，分隔线 | 标题真实链接；必要操作独立 | 没有封面时移除图槽；不把整行链接和按钮嵌套 |
| 状态标签 | 语义文字/背景配对 | 静态状态不进 Tab 顺序 | “未检测”“失败”“陈旧”写文字；不以灰点代替状态 |
| 抽屉/对话框 | surface，标题、关闭按钮 | 开启后焦点进入，约束在弹层，关闭归还触发器 | Escape 关闭实际弹层；有未保存数据时说明后果 |
| 页面反馈 | 标题、说明和下一步动作 | 错误摘要可聚焦具体问题 | 空结果、失败、未配置分别设计，不用同一“暂无数据”覆盖 |

控件最小热区 44×44px，相邻紧凑控件通常留 8px；正文内联链接另按可读行距处理。图标使用一致线性图形并附可访问名称，不用 emoji 替代 UI 图标。抽屉和主题菜单关闭需恢复滚动与焦点。

加载状态保持内容区尺寸；首次加载可用安静骨架，已有结果刷新则保留旧内容并明确“正在更新”。reduced-motion 取消进入位移、淡入和骨架闪动，保留静态状态文字；不用动效作为唯一等待提示。

输入错误只因相关字段重新校验通过而清除，不因再次获得焦点消失。提交失败同时在面板顶部概述和字段旁定位，避免只有短暂 toast；成功提示适度播报，保存状态不逐按键播报。

## 4. 关键局部设计

### 4.1 精选、作品与工具

精选桌面左侧 7 列主推荐、右侧 5 列上下两项；手机依次主、次、次。主次由布局与标题层级区分，不用随机旋转。可无图；主推荐有图时 16:9，原图不裁掉信息性文字。少于三项自然收缩。

每件作品桌面一行，预览约占 7 列，说明 5 列；三件方向一致，不强制交替。手机图上文下。真实截图可完整显示，图片太长时使用明确预览加“查看详情”，不把截图里的文字当页面正文。工具紧凑列表显示名称、用途、文字状态、打开按钮；手机按钮单独一行以容纳长用途。

### 4.2 详情与评论

详情顺序为类型、标题、日期/更新、标签/系列、可选封面、正文。桌面目录只出现于实际有标题的长文；手机“文章目录”展开在文档流中，不侵占整段阅读。锚点跳转后标题可见，脚注有返回入口。

代码复制保留成功/失败反馈；表格横向滚动区有可见提示且可键盘访问。公式与 Mermaid 渲染失败仅影响当前块，保留源码或文字说明入口。评论失败显示“评论暂时无法加载”及重试；已知 Discussion 才显示直达链接，不伪造不存在的讨论地址。

### 4.3 编辑器与发布面板

≥1280px 可使用源码/预览两栏及可收起的 280px 设置栏；1100–1279px 设置改抽屉，编辑/预览仍按可用空间决定并排。窄屏使用编辑、预览两个标签，元数据设置独立面板。源码区最小可用宽度约 360px；不足时切换单栏，不硬挤。

发布面板桌面居中最大 640px，内容长时面板内滚动；手机全屏，提交区在安全区域内但不能遮住字段。先展示目标版本与公开 URL，再展示字段校验和文件公开范围，之后是立即发布/指定时间。已有排期时默认“取消原排期”，选择保留时展示到期替换说明，主按钮反映后果。

冲突面板桌面并排两份稿，手机本地/服务器切换，永久保留导出本地稿入口。不要把“用服务器稿替换”设计成不解释后果的默认主动作。键盘和输入法打开时保留光标可见，不固定底部多排工具栏。

### 4.4 媒体、认证与运维

媒体桌面栅格和元信息侧栏，手机单列；每项显示处理状态、尺寸、文件大小、公开范围和引用关系。展示图可公开而原图受保护时分别说明；“移除引用”与“删除文件”不能共用文案。首版不增加批量删除入口。

登录使用最大 440px 的安静表单，无首页 Banner；账号/密码标签、显示密码、登录按钮、GitHub 登录及服务器恢复说明。支持粘贴和密码管理器；GitHub 取消/失败有返回密码登录的路径，无注册入口。

概览先显示异常，再最近草稿、24 小时排期、服务入口。备份卡片分别列本机成功时间、异地恢复点、回执时间；状态陈旧仍保留原始成功时间。服务卡片明确“站长标记”与时间，不显示自动健康脉冲点。

## 5. 设计验收边界

本轮完成语义色、尺寸、组件状态及页面线框文档；配色仅验证了 46 组纯色配对。下列项目仍待实际视觉稿和之后实现验收：实际插画裁切及叠字、中文字体效果、代码高亮、320/375/768/1099/1100/1440px 排版、200% 字体缩放、键盘焦点及移动输入法。

线框文本不是全量渲染图，也不证明没有溢出。正式规格最终批准前需对完整桌面/手机/深色视觉稿做可视审阅；本轮不写 HTML/CSS、不安装依赖、不创建项目或部署。
