## 1. 范围与边界

首版为单站长、无公众注册的 SvelteKit + PostgreSQL 综合站；独立 Compose 部署，不修改现有容器。公开内容、Markdown 管理、版本、排期、搜索、媒体、Giscus、站长服务目录纳入；私人日记、任务、文件工作台、相册、动漫追踪后置。作品展示已纳入首版，不因“相册/作品集后置”的历史措辞而被移出范围。友链暂放关于页，资源页保持资源目录职责。

公开首页维持已确认顺序：导航、稳定场景 banner、简短介绍、6 条最近更新、3 篇精选、最多 3 件作品、最多 3 个工具、三组页脚。精选允许重复且无需为 SEO 强制另写摘要。无精选、作品、工具时隐藏对应区块；无公开工具时同时隐藏主导航工具项，直接访问工具页显示诚实空状态。不展示私有服务的数量、名称或地址。

视觉沿用已确认综合 v2、蓝紫主色与 Noto Sans SC / Space Grotesk / JetBrains Mono。无固定角色，不用星星、网点、旋转叠卡；局部不对称通过精选主次与图文比例体现。旧草图中的小样数量和合并“作品与工具”不覆盖独立分区规则。后续全量草图必须画全 6/3/3/3 的内容及移动、深色状态。

内容列表每页 20 项，类型、编辑/发布/排期状态、标签和关键词可筛选；状态可并存，例如“已发布＋有未发布修改＋有排期”。每行显示标题、类型、最后编辑、公开时间、排期及操作。草稿默认打开编辑器；已发布内容提供查看公开页。首版不做批量删除，归档与撤回均保留数据，不将归档伪装成删除。

## 3. Markdown 编辑与预览

桌面宽度足够时源码与预览并排，支持专注编辑；窄屏采用编辑/预览标签页，切换不丢失正文、选区与滚动位置。顶部显示标题、保存状态、预览、保存版本、发布；右侧设置摘要、封面、标签、slug、评论开关，并显示系列归属与管理入口；系列修改独立显式保存，移动端进入独立设置面板。

基础工具栏插入 Markdown，表格使用源码与模板，不实现电子表格编辑器。支持 CommonMark、表格、任务列表、删除线、代码高亮/复制、目录、脚注、公式与 Mermaid。推荐 CodeMirror 6；渲染推荐 unified/remark/rehype、KaTeX、Shiki，Mermaid 按需加载并启用严格配置。具体兼容版本在后续获准的实施计划中安排验证，验证通过前不冻结依赖，不在此声称已验证。

预览和公开正文共享解析与清理规则；原始 HTML 默认不执行，禁止 MDX/脚本组件与任意 iframe。代码高亮在服务端完成，Mermaid 出错保留源码与提示，不能令整篇文章失败。大型图可展开查看，代码/表格只在自身容器横向滚动。预览路由仅站长可访问，响应 `no-store`。

自动保存采用停止输入约 2 秒后保存；连续输入时最长约 15 秒尝试一次，仅更新编辑稿。界面区分未保存、保存中、已保存时间、失败、离线、会话过期和冲突。保存响应只能确认对应版本，迟到响应不能覆盖新输入。多标签页采用修订号乐观锁，冲突保留两份并提示比较，不能静默最后写入覆盖。

未保存内容保留在当前编辑器内存，离开提示；不默认长期写入共享设备 localStorage。网络或会话失败时允许复制或导出当前 Markdown，重新登录后重试；不能宣称内存保护能抵御浏览器崩溃。自动检查点：存在变化且距上次检查点至少 10 分钟时生成；手动保存、发布、更新排期另外生成不可变快照。不自动清理历史。

## 4. 发布、版本与排期

发布面板列出目标版本、标题、URL、摘要、封面、标签、评论开关与上传状态；标题/slug 无效、媒体上传未结束或引用不可访问时阻止发布并定位问题。无封面/无标签不阻止发布。提供立即发布与指定时间；更新时间采用 Asia/Shanghai 显示，数据库使用 timestamptz。

内容具有编辑稿、当前公开版本及至多一个有效排期；状态不是互斥单选。已发布内容继续编辑不改变公开页。排期固定版本，继续编辑不替换它；更新排期版本是明确操作。恢复旧版本只生成新编辑稿；不改线上也不改有效排期。

版本列表显示时间、来源（手动/检查点/发布/排期）、摘要差异；比较包括正文、标题、摘要、封面、标签等。撤回停止本站公开访问、索引与 RSS 分发，并原子取消未来排期以避免自动重新公开；保留所有版本。撤回说明明确已公开附件、搜索引擎副本与 GitHub 讨论无法保证撤回。

应用进程每 30 秒检查到期排期，运行正常目标一分钟内发布。数据库事务行锁与排期状态比较防重复；发布指针、公开检索投影与审计同事务更新。失败保留原因及重试入口；瞬时失败有上限退避，内容校验失败不无限重试。重启补发有效排期，记录实际时间；已取消排期永不补发。

重要更新使用本次发布操作的明确标记和事件时间，不随历史版本恢复自动触发；首页每项内容只出现一次，用最近的首次公开/重要更新事件排序，显示“更新”标记。普通修订不刷新排序。RSS 保留稳定条目 ID，更新不得伪造成全新文章。

## 5. 内容模型与系列

推荐 PostgreSQL + Drizzle ORM/迁移工具，仍保持可读 SQL；首版不是通用可视化 CMS。推荐关系如下：

| 实体 | 职责 |
|---|---|
| content_items | 稳定 UUID、类型、编辑修订号、公开版本指针、归档标记、时间 |
| content_url_aliases | 当前与历史公开路径归属；目标 slug 来自发布版本，发布时切换 |
| content_drafts | 当前可变稿，字段按类型校验 |
| content_versions | 不可变标题、Markdown、摘要、封面、类型扩展字段及关联快照 |
| tags / version_tags | 标签实体与版本关联，避免草稿改线上 |
| series / series_members | 系列元信息、成员、人工序号 |
| publication_schedules | 内容、版本、到期时间、执行状态、失败原因 |
| media / media_variants / media_references | 文件键、派生图及草稿/历史/排期引用 |
| users / oauth_accounts / sessions | 单站长认证、稳定 GitHub ID、可撤销会话 |
| service_links / site_settings / audit_events | 私有服务目录、配置、可追溯操作 |

文章、笔记、动态、作品、公开工具与资源共享基础实体，类型扩展字段按固定 schema 校验，不允许任意字段袋。工具存用途、入口与状态，资源存来源和外链；它们的公开说明也遵守版本发布边界。动态可无独立标题，由正文生成展示摘要，稳定 ID 与 slug 不依赖摘要。

系列推荐允许混合文章与笔记；首版每篇至多一个系列，系列含名称、简介、可选封面，支持草稿/公开/归档。归档系列仍可阅读，退出首页主动推荐；草稿系列不公开。成员用上下移动按钮排序，桌面拖动仅作增强，键盘可完成同一操作。公开计数及上一项/下一项只使用公开成员，不显示草稿或私有总数；不做“共计划 N 篇”完成率。系列变更在后台显式保存公开设置，不随正文自动保存。

## 6. 媒体与访问控制

上传文件先进入受保护暂存区，校验实际类型、尺寸、大小，生成不可变随机文件键；数据库标记 pending/processing/ready/failed。草稿原图与派生图通过认证媒体路由访问，不提前放入公开静态目录。首版上传白名单支持常用位图、PDF、视频，SVG/HTML 等主动内容不直接内联；附件下载使用安全响应头。

发布前先准备并校验公开派生文件，再事务切换公开版本；准备失败保留旧公开页。已生成但未发布的副本不自动删除。每项上传显示进度、失败原因和重试；替换图片产生新键，旧版本仍可读取旧图。历史与排期引用计入使用状态。

公开 URL 只用于明确发布的附件；私人附件始终鉴权且 no-store，不因猜到 URL 即可读取。已公开文件按不可变资源处理，撤回文章不自动承诺附件重新保密；需要撤销公开附件时另行设计逐项下线并提示外部缓存无法回收。图片处理区分截图/照片/透明图/动画，原图不覆盖。

推荐初始上传上限：图片 20 MiB、PDF 50 MiB、视频 100 MiB，图片处理像素上限 40MP、并发 1；实际阈值须以服务器内存和样本校验后定。磁盘低于 15% 警告，低于 10% 停止新增媒体处理并保留阅读/编辑能力；日志和数据库也需空间保护，不能把这些阈值视为磁盘不会满的保证。

## 7. 搜索、URL 与缓存

沿用独立搜索页、回车提交、URL 保存过滤条件、每页 20 条结果。公开详情路由按类型为 `/articles/[slug]`、`/notes/[slug]`、`/moments/[slug]`、`/projects/[slug]`、`/tools/[slug]`、`/resources/[slug]`；修改 slug 保存旧地址重定向，不更换内容 UUID。服务入口仅 `/workspace/services`。

搜索初版推荐 PostgreSQL 公开检索投影，字段从当前公开版本生成。标题、标签、摘要、正文依次加权；中文先验证规范化子串匹配与 pg_trgm 候选加速，短词回退有界匹配，英文可使用内置全文能力。不声称 pg_trgm 等同中文分词；用中英文、单字、短语、标点、代码名与撤回样例决定最终查询，未通过前不能冻结索引实现。

首版数据库内容页采用 SSR，不使用必须重建网站才更新的预渲染。公开查询直接读取公开版本，暂不引入跨请求正文缓存；静态 hash 资源可长缓存。私有页面、预览、认证响应 no-store，CDN 不缓存会话页面。后续若引入缓存需按发布/撤回事件明确失效。

筛选组合与搜索页默认 noindex；规范标签/系列页可索引。分页每页有自身 canonical，不把所有页 canonical 到第一页而隐藏旧内容。RSS 首版分发文章、笔记、动态、作品公开版本，资源/工具目录可由站点地图发现；此为分发细化推荐。OG 标题与站点身份为主，banner 可作底图，不能强制另维护首页重复摘要。

## 8. 认证与账号安全

初始化命令创建唯一站长，无公网初始化/注册接口。密码使用 Argon2id；推荐 GitHub OAuth 使用成熟 OAuth 客户端（如 Arctic）与服务端 state 校验，客户端密钥不进前端。绑定稳定 GitHub 数字 ID，不按可改名账号或邮箱自动合并。具体库与安全配置实施前核对维护状态及官方说明。

会话为高熵随机 token，数据库存摘要，HttpOnly/Secure/SameSite=Lax cookie；推荐最长 7 天、闲置 24 小时失效。写请求执行服务端授权与来源/CSRF 校验；更换密码、绑定/解绑身份要求近期重新认证，撤销其他会话。安全页可查看并撤销会话。

登录页是站长入口而非注册页，同时提供账号密码和 GitHub；失败提示不泄露账号是否存在，成功后回到原受保护路径。账号安全页显示会话、GitHub 绑定状态和安全事件；敏感变更要求重新认证且不可解绑最后一种可用方式。登录界面不加载公开站场景 banner，避免把认证入口做成营销首屏。

GitHub 绑定从已登录设置页发起；不允许未绑定身份获得站长权限，不解绑最后一种可用登录方式。更换 GitHub 需验证新身份，恢复由服务器管理命令完成并写审计；不新建邮件系统。登录限速同时按账户及来源，避免仅按 IP；日志不记录密码、令牌和完整私有正文。

## 9. 评论和服务目录的真实能力

Giscus 是外部 GitHub Discussions 评论，不存在本站默认的“待审核队列”。首版工作台评论页展示仓库配置、每篇开关、相关 Discussion 与 GitHub 管理入口；不承诺未读数、待处理计数和实时同步。需要这些功能时再设计 GitHub API 权限、拉取和失败状态。

服务目录保存名称、说明、URL 与站长手动状态。默认状态“未检测”，不自动探测目标、加载 iframe、抓取目标网页或使用 Docker socket；不因为卡片能打开就声称服务健康。URL 禁止 javascript 等危险协议，不把凭据塞进链接。现有四个服务的地址/TLS/认证需接入前逐一只读核实。目标服务鉴权保持原状。

服务卡片的状态明确区分未检测、站长标记可用、站长标记维护和站长报告不可用，人工状态带更新时间；卡片以用途为主，外链使用安全 URL 与安全打开策略。打开外链不代表已检测目标，也不能据此自动记录目标“上次打开失败”；浏览器通常无法在不探测的前提下得知跨站加载结果。若未来需要自动健康检查，另行设计目标授权、频率、隐私和失败降级。

## 10. 部署、备份和运行可见性

推荐 SvelteKit adapter-node 应用容器 + PostgreSQL 容器的独立 Compose；数据库仅内网。镜像构建在开发机/CI，服务器运行不可变版本；Node LTS、PostgreSQL 主版本及依赖小版本在实施前核验并固定，不使用浮动 latest。数据库迁移由单独受控命令执行，不在每个 Web 实例启动时自动执行。

部署前重新核实宿主机容量、现有容器占用、域名/TLS/Cloudflare Tunnel 路由；只配置本站入口。应用与数据库健康检查分开，公开健康接口不泄露版本与服务目录。后台显示排期最后执行、服务器备份完成、Mac 拉取完成、磁盘使用及信息采集时间。

每日服务器 pg_dump 一致性备份；Mac 在线时由 launchd 触发拉取，支持联网后补拉。数据库快照和媒体不可变清单绑定，复制完成校验后写成功标记；不使用带删除语义的镜像同步。Giscus 用分页 GitHub API 单独导出讨论与回复，权限最小化，记录导出失败；此副本不保证原身份/时间无损回灌。所有调度留在实施阶段，不在本轮创建。

备份不自动清理，容量阈值与趋势提示人工处理；不声称无限保留。恢复点约一天仅在每日异地复制成功时成立；Mac 离线扩大窗口。恢复时间以首次隔离演练实测，不先承诺。升级先备份、校验迁移，再部署；破坏性迁移不依赖回滚旧镜像解决。恢复演练使用新目录/数据库，不覆盖现有服务。

## 11. 验收与剩余输入

设计验证：375/768/1099/1100/1440px、浅深主题、长标题、无图、少内容、空结果、网络失败、键盘和 reduced-motion。手机菜单不遮挡焦点，搜索是独立页而不是被 Escape 关闭的面板；Escape 只关闭实际弹层。文字与交互色分别验证对比度，辅助文字不能因强调“轻”而不可读。

行为验收：编辑不改线上；双标签页冲突不丢稿；排期/取消竞争不重复发布；重启补发；恢复不替换公开版本或排期；草稿媒体不可匿名访问；撤回不出现在公开查询；备份恢复可重建内容与媒体引用；无 GitHub 身份抢占管理员；现有容器不变。

性能目标为待实测验收目标：代表性移动设备 LCP ≤2.5s、CLS ≤0.1、INP ≤200ms；本地实验不等于真实用户分位数据。优先 banner 请求，不延迟其显示；字体 swap，正文优先；非首屏精选图不能因名为“精选”就全部抢占高优先级。

上线前需提供或核实：站点名称/定位文案、域名、GitHub 绑定 ID/OAuth 配置/Giscus 仓库、实际服务地址、最终授权插画、首批内容与工具、备份目录与运行时间、服务器余量。缺这些不妨碍当前设计，但不能宣称可部署。

正式规格审阅时需要一起审阅本文、功能分册、当前 UI 规则及后续全量桌面/手机/深色设计稿。技术候选需要文档核验及代表性样例后才能标为验证完成；尚未验证的条件和失败处置在获准后的实施计划中落实。在用户批准正式设计规格前不进入 writing-plans。

### 12.2 发布与排期操作契约（R1）

所有发布、撤回、取消、恢复和排期更新都检查最新修订及状态。面板展示之后如果状态被另一标签页或排期任务改变，操作必须停止并提示重新核对，不静默使用过时选择。重复提交相同发布请求不重复生成发布事件。

| 操作 | 编辑稿 | 公开版本 | 有效排期 |
|---|---|---|---|
| 自动保存/手动保存版本 | 保存当前稿，后者额外留快照 | 不变 | 不变 |
| 新建/更新排期内容 | 保存经确认的稿并留快照 | 不变 | 绑定面板列出的快照与时间 |
| 只调整排期时间 | 不变 | 不变 | 保持版本，更新时间并记录操作 |
| 立即发布当前稿 | 保存并形成发布快照 | 切换到该快照 | 无排期则无需处理；有排期必须明确取消或保留 |
| 提前发布排期版本 | 不覆盖正在编辑的稿 | 切换到排期绑定版本 | 消耗该排期，不再到点执行 |
| 撤回 | 保留 | 移除公开指针 | 同事务取消 |
| 恢复历史版本 | 先保护当前未保存内容，再生成新稿 | 不变 | 不变 |
| 取消排期 | 不变 | 不变 | 取消并留记录 |

手动发布时有三种可行策略：默认取消、始终保留、禁止发布直到单独处理排期。推荐默认取消，同时允许在发布面板显式选择保留，兼顾避免旧内容覆盖与提前安排后续更新。主按钮文案反映选择，例如“发布并取消排期”；保留时显示到期时间及届时会替换当前公开内容的说明。

撤回与排期执行竞争时按数据库串行结果处理：撤回成功后不得再次由该排期公开；已经执行的排期不可再显示“取消成功”。对过期状态返回实际结果。

“重要更新”是本次发布事件属性，默认关闭，不随恢复版本自动再次触发。首次公开时间一经建立保留；撤回后重新公开不会伪造首次发布时间，需要回到最近更新时显式勾选重要更新。

### 12.3 内容归档、URL 与公开设置（R2、R3）

推荐内容归档为后台收纳标记，与公开/草稿/排期相互独立。界面写“归档（不改变公开状态）”，可恢复；默认内容列表排除归档项，但排期总览和异常提醒仍包含归档内容。取消公开必须使用撤回。另一种可行方案是将归档定义为撤回，但与现有撤回动作重复，故不推荐。

系列仍沿用原推荐：归档系列可公开阅读，退出主动推荐；草稿系列仅站长可见。系列和内容的归档对象及后果分别在确认界面解释。

内容 UUID 及已发布类型稳定；首版首次发布后不提供类型转换，避免路径和专有字段迁移。slug 可在草稿中修改，只有发布选定版本时才更新公开 URL。排期版本包含目标 slug，到期再检查唯一性；冲突则排期失败并保留旧公开页。系统同时保留历史别名，禁止新内容占用其他内容的历史地址。

所有历史地址直接跳转到当前规范地址，避免重定向链；恢复旧版本不会自动回滚 URL，面板要求核对目标 slug。撤回内容的当前及历史入口均返回统一的公开不可用页面，不泄露草稿标题；公开响应为 404，站长可从工作台查看。Giscus 使用稳定内容 ID 映射，不跟随 slug 或标题改变。

设置生效边界：

| 设置 | 保存位置及何时生效 |
|---|---|
| 标题、正文、摘要、封面、标签成员、slug、每篇评论开关、工具入口与状态 | 编辑稿中修改，经发布/排期版本生效 |
| 系列名称、简介、封面、状态、成员、顺序 | 系列管理页显式保存；面板列出公开影响，不跟随正文自动保存 |
| 首页精选与展示排序 | 站点设置显式保存，仅能展示当前公开内容；撤回即退出展示 |
| Banner、站点名称、定位与公开链接 | 站点设置预览后显式保存；新图按同样媒体公开授权流程处理 |
| 标签重命名 | 全局管理动作，保留 ID、展示影响范围；历史版本关联不因此被重写 |
| Giscus 仓库与分类 | 全站配置动作，显示可能改变评论关联的影响；每篇开关仍按内容版本发布 |

系列成员只在系列管理页修改；编辑器内展示已保存归属并提供管理入口，避免一个关系既随发布生效又立即保存。快照可记录当时系列作为历史说明，但恢复内容不会恢复整个系列关系。标签快照保留当时名称便于差异比较，公开展示使用当前标签名称；成员变更仍必须发布。

### 12.4 媒体授权及发布校验（R4）

区分文件已就绪与允许公开两个维度。新上传资源默认未公开；先生成文件并检查可读取，但放在受控存储中。发布事务同时提交版本、检索投影、媒体公开授权和审计，匿名媒体路由只读取已提交的授权。不能将尚未发布的文件提前复制到可直接访问的静态目录；不可猜测的随机键只是命名手段。

准备失败或事务回滚：旧公开版本继续可用，新文件保留受保护状态且不自动删除。若事务成功后文件读取异常，显示局部媒体错误并记录运维异常，不假装数据库事务能保证文件系统永久可用。

公开展示图与原图分别授权。推荐正文默认公开展示版本，原图仍保存受保护；只有显式选择提供原图下载时才公开原图。PDF/视频需要发布其实际文件时，在发布面板列出文件及公开范围。已公开媒体引用到草稿中不会重新变成私有；编辑器显示“已公开”提示。

“引用不可访问阻止发布”仅针对本次版本引用的站内媒体、就绪状态及授权适用性；不探测所有外部链接，不因外站暂不可达阻止文章发布。不自动下载外部 Markdown 图片，避免后台对任意 URL 发起请求。首版外部图片保留为来源链接，欲内联展示需由站长上传获授权副本。

图片首版白名单建议 JPEG、PNG、WebP、GIF、AVIF；PDF 可下载，视频建议 MP4/WebM，不承诺所有编码都可播放，不增加转码服务。动画若没有能保留语义的派生版本，提供经确认的原动画或下载入口，不悄悄变成静态图。高像素或超限文件就地说明原因，不进入无限重试。

### 12.5 Markdown 导入导出及迁移（R6）

首版导入单个 UTF-8 `.md` 为新草稿，不覆盖既有内容、不直接发布、不执行 HTML/脚本；导入后展示标题、正文和未解析媒体提示。标题缺失时由作者补充，动态仍允许无独立标题。首版不要求理解任意博客系统的 front matter；未识别元数据保留在导入预览并提示，不静默丢弃。

导出明确选择当前编辑稿、当前公开版或某一历史版本；输出原始 Markdown，并提示站内媒体引用仍需文件。会话过期时允许导出当前内存正文，导出不代表服务端保存成功。

完整迁移包与单篇 Markdown 导出分开：迁移需包含可读内容元数据、稳定 ID、版本、标签/系列关系、媒体键及文件清单；由后续受保护管理命令提供，首版不额外增加迁移 GUI。用于恢复的数据库备份仍包含权限、排期及必要配置；会话 token、密码摘要和密钥不得混入公开内容导出包。

### 12.6 页面、编辑恢复与可访问性（R7）

补充 `/updates` 为首页“查看全部”的混合更新列表，仅文章/笔记/动态，使用首页同一排序规则；每页 20 项，真实分页链接。`/privacy` 说明会话 cookie、Giscus/GitHub 第三方数据、外链及实际日志用途，不声称绝不收集任何信息。`/login` 为站长登录入口，受保护路径登录后仅允许回到本站合法路径。

普通内容列表默认按首次公开时间倒序；作品和工具首页使用手动展示顺序。筛选变化重置页码；返回列表恢复原查询与位置。工具名称链接说明页，独立“打开工具”访问入口，避免整行链接嵌套按钮。无公开工具时仍遵循已有隐藏规则。

详情正文沿用 65–75ch 的建议上限；中文实际行长须用中文长文验证，不能将 ch 当作汉字数量。系列导航明确使用人工顺序；普通上一篇/下一篇使用同类型首次发布时间顺序，同一目标不重复展示。相关内容推荐按公开标签交集匹配最多 3 项，无匹配则隐藏，不新增 AI 推荐。

编辑冲突显示本地稿与服务器稿的时间/修订号及可复制差异。操作为继续比较、以服务器稿为新基线后合入本地修改、或明确放弃本地修改；任何覆盖当前内存正文的动作先允许导出。本轮推荐不增加自动合并算法。

会话过期时编辑器保持原位，通过独立登录页/标签完成认证后主动重试保存；仍检查修订号，不能登录成功后无条件覆盖服务器稿。离开提示覆盖站内导航与可用的浏览器关闭提醒，但不承诺在所有移动系统退出时可靠触发。

失败应说明恢复动作，并在相关字段旁定位错误；发布失败不关闭面板、不丢选择。保存结果与错误适度播报，不逐按键播报。移动编辑的工具栏、输入法与安全区域不得遮住当前光标或主要操作。非正文触控控件不少于 44×44px；正文内联链接通过清晰样式和行距保障可点。

验收增加 320px 窄屏与 200% 字体缩放；导航可提前收纳。正文/辅助文字对比度至少 4.5:1，必要的控件边界及焦点指示至少 3:1；焦点不能被吸顶导航和抽屉遮挡。视频无自动播放；需要传达语音信息的视频应提供字幕或等效文字说明。Mermaid 同时提供源码或文字说明入口。

### 12.7 工作台运行信息的来源

“保存失败”若仅发生在当前浏览器，只在当前会话展示，不能包装成跨设备全局指标。排期失败来自数据库任务记录；磁盘来自本站挂载存储的实际采集；服务器备份和 Mac 拉取是两条独立记录，带完成时间、校验结果及采集时间。

Mac 拉取完成后，通过受保护运维通道回写经过校验的完成记录；不能以服务器完成备份时间推断 Mac 已收到。未配置、无记录、过期或读取失败都显示对应状态。功能分册推荐使用拉取所需的 SSH 通道、专用备份账户和受限回执接收命令，并定义新鲜度阈值；尚未核验服务器环境或创建调度。

### 12.8 补充验收场景

- A1：已有排期，手动发布默认取消；显式保留时面板显示未来覆盖说明，到期结果与选择一致。
- A2：发布与撤回/取消同时发生，最终公开状态与事务顺序一致，不出现撤回成功后旧排期重新公开。
- A3：修改 slug 后自动保存不改变公开地址；发布后所有旧地址直接跳转当前地址；历史地址不可被别的内容占用。
- A4：媒体准备完毕但发布未提交，匿名访问原图和所有派生图均失败；已授权公开的旧媒体行为不受草稿编辑影响。
- A5：原图未选择公开时，即使展示图已公开，匿名也不能下载原图；发布 PDF/视频前明确文件公开范围。
- A6：内容归档不等于撤回，排期与异常仍可发现；系列变更、标签重命名与内容恢复符合独立生效约定。
- A7：外链打开不制造服务健康结果；人工状态带来源与时间；单个服务故障不影响工作台。
- A8：导入产生草稿且不获取远程资源；会话过期仍可导出内存稿，重登后的冲突不丢稿。
- A9：按键盘完成筛选、发布、冲突处理与系列排序；320px 和字体缩放下焦点、正文及编辑光标可见。
