首版包括 Markdown 管理、导入导出、历史版本、定时发布、搜索、媒体、Giscus、服务目录、备份及恢复验证。具体新工具程序未被定义，不因画板出现 JSON 格式化等示例就把它当成交付功能。

后置：私人日记/任务/文件工作台、相册、动漫追踪、公众注册、深度服务 API、Docker 控制、独立搜索服务和复杂 CMS。作品本身是首版，不因历史“作品集后置”措辞被错误移除。

## 5. 已确认视觉与页面方向

- 综合方案 v2：现代主题组件＋日系场景 Banner＋个人小窝信息架构＋安静文章流。不是重新选择站点风格的阶段。
- 首版无固定吉祥物或角色；稳定单 Banner，可配置手机图/焦点/署名。不使用樱花、星星/网点、鼠标特效、随机旋转、持续晃动、音乐播放器或统计堆叠。
- 首页顺序：导航 → Banner → 简短个人介绍 → 6 条更新 → 3 篇精选 → 最多 3 件作品 → 最多 3 个公开工具 → 三组页脚。介绍与更新为前后分区。

- 作品桌面图文左右分行，手机图上文下；工具紧凑列表，维护项禁用打开但保留说明。没有公开工具时隐藏公开工具导航和首页区块；私有服务不进入公开区。
- 桌面 ≥1100px，平板 768–1099px，手机 <768px；空间不足提前收纳导航。工作台桌面 240px 侧栏，手机抽屉。文章不重复首页大 Banner。
- 蓝紫主色 #6D5CE7；浅底 #FBF9F7、深底 #171522；深色主按钮 #B5A6FF 配 #241A46，链接/焦点 #C5B9FF；完整表见视觉分册。
- 中文 Noto Sans SC，少量英文数字 Space Grotesk，代码 JetBrains Mono。当前 PNG 实际用 Hiragino Sans GB 代替，须在工程验证目标字体。
- 普通文字对比度目标 4.5:1，控件边界/焦点 3:1；热区通常 ≥44×44px，焦点环 2px。尊重 reduced-motion，不靠颜色或 hover 单独传意。

## 6. 技术与部署边界

自建 SvelteKit + PostgreSQL，一个全栈应用。独立 Compose 中 Web 与数据库分容器，数据库仅内网，浏览器不直接连数据库；不修改现有容器。

当前推荐候选：adapter-node、Drizzle 及可审阅 SQL 迁移、CodeMirror 6、unified/remark/rehype、Shiki、KaTeX、严格 Mermaid、Argon2id、成熟 GitHub OAuth 客户端（如 Arctic）。是待版本/维护状态验证的候选，不是已安装或验证兼容。保持正常依赖核验，不重启 Halo/CMS 或数据库选型。

数据库内容页面 SSR，发布不需要重建网站；首版无跨请求正文缓存。静态哈希资源可长期缓存，私有/预览/认证响应 no-store。不提前加 Redis、Elasticsearch、向量库、图数据库、MinIO 或独立消息队列。

服务器历史只读资料：Ubuntu 24.04.4 LTS x86_64，4 逻辑 CPU，约 3.6 GiB RAM，40 GB 根盘；2026-09-25 曾可用约 17 GB。地址 49.233.199.110。这些不是当前实时检查结果，部署前重新核验。

现有容器：cpa-manager-plus、zotero-pdf2zh-v3、navidrome、cli-proxy-api；保持不动。容器名不证明域名/TLS/认证已配置。本站只提供站长外链入口，不挂 Docker socket、不探测、不 iframe、不提供单点登录。

Cloudflare Tunnel 只是候选入口，实际路由/子域名/TLS 未核验；不默认可用。镜像构建在开发机/CI，迁移单独受控运行，不每个 Web 实例启动时自动迁移，不用浮动 latest。

## 7. 内容、版本和发布的不可混淆规则

统一内容实体＋可变编辑稿＋不可变版本＋当前公开指针＋至多一个未结束排期。类型专有字段按固定 schema 校验；草稿可不完整，发布/排期时才检查必填。

六类：文章/笔记需标题与正文；动态可无标题但需有效内容；作品需名称、说明、正文、状态；工具需名称、用途、状态，可用时需入口；资源需名称、说明、来源名称与 URL。完整字段长度/摘要/slug 规则见功能分册，不凭交接摘要替代表格。

- 自动保存约停止输入 2 秒、持续输入最长约 15 秒尝试；只更新稿。响应确认修订号，多标签乐观锁；冲突保留本地及服务器稿，不静默覆盖。
- 有变化且距上次检查点至少 10 分钟生成检查点；手动保存版本、发布、排期绑定保留快照。不自动清理历史。
- 草稿、公开、排期、归档按维度组合，不建互斥单一状态枚举。“归档”只影响后台收纳；异常/排期仍可见。
- 立即发布有旧排期时默认取消，可显式保留且说明未来替换；提前发布排期版消耗该排期。撤回移除公开指针并原子取消有效排期。
- 排期固定快照，不随继续编辑改变；恢复旧版本只生成新稿，不覆盖公开版或有效排期。
- 30 秒轮询，正常目标一分钟内发布；停机恢复补发仍有效任务，事务/锁/幂等保护。重试策略、失败恢复见功能分册。
- 重要更新是发布事件，恢复旧稿不自动再次触发；RSS 条目 ID 稳定，重新公开不伪造首次发布时间。
- UUID 稳定；slug 随发布切换、旧路径保留归属并直达当前地址，不能被其他内容占用。撤回的当前/历史入口公开 404，不泄露草稿。
- 标签人工选择，不自动 AI 生成。系列可混合文章笔记，每篇至多一个，关系与排序独立显式保存，公开只统计公开成员。
- Markdown 导入单篇生成新草稿，不覆盖/发布、不抓取远程资源；导出明确版本。完整迁移包与正文导出、灾难恢复备份分开。

## 8. 媒体、认证和评论

原文件在宿主机持久目录，数据库存键与元数据；正文不保存宿主机绝对路径。保留原图，按图片性质生成展示版本，不覆盖历史文件。

媒体准备完成不等于公开：生成过程中仍鉴权，发布事务提交后才授予明确资源匿名访问；随机 URL 不能代替权限。展示图与原图分别授权，原图默认私有；需要提供原图/PDF/视频时面板明确公开范围。撤回正文不承诺已公开文件、外部缓存或 GitHub 讨论保密。

草稿、原图和所有未公开派生图受保护，私人文件 no-store。发布校验只针对站内引用，不探测所有外部链接；外部 Markdown 图片先保留为来源链接，不后台抓取。

媒体阈值为待资源实测初值：图片 20 MiB、PDF 50 MiB、视频 100 MiB，40MP、处理并发 1。无自动批量删除/清理；未引用和历史引用不能随意删。低容量要提示并限制新增处理，不承诺磁盘耗尽仍可保存。

认证：初始化命令创建唯一站长；密码 Argon2id；GitHub 绑定稳定数字 ID，不按用户名/邮箱自动合并，不让首个 OAuth 访客成为站长。服务端会话摘要存储，最长 7 天/闲置 24 小时推荐，安全 Cookie、来源/CSRF 检查、限速、敏感操作重认证与会话撤销。服务器命令恢复，无邮件系统/公众注册。

Giscus 使用官方 giscus.app 和独立公开 Discussions 仓库，草稿/私人页不加载。文章/笔记/作品默认开，动态/工具/资源默认关；开关随版本发布。本站无待审核/未读计数，管理页提供配置和 GitHub 入口；未知 Discussion 不编造链接。本站 GitHub 登录与评论授权是不同配置。

## 10. 备份、运行状态与恢复
