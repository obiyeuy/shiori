日期：2026-09-25。状态：文字线框设计，供正式规格审阅；不是已渲染的 UI 截图。尺寸与主题使用《视觉与组件规格》。本稿含完整首页数量、关键页面顺序、手机重排和异常状态。

后续进度：线框已有首批静态画板，见《个人综合站-静态视觉稿-v1-审阅索引》。下方覆盖表保留线框提交时状态；新索引逐项说明当前已渲染范围与尚未完成的部分，不能将首批画板视作全量最终稿。

## 1. 示例内容与阅读方式

以下站名“某人的小窝”与内容标题均为设计占位，不当作真实站点身份、已有文章或真实上线工具。正式素材后补。所有页面浅/深模式使用同一结构，替换语义色，不反转图片或改变内容顺序。

首页样例包含六条更新、三篇精选、三件作品、三个工具；实际数据不足自然收缩，不生成虚假条目。1440px 桌面按最大 1280px 容器，375px 手机按 343px 外容器校核。线框图中的横向线条只表示分区，不要求实现为边框。

## 4. 首页状态差分

| 状态 | 保留 | 改变 |
|---|---|---|
| Banner 加载中/失败 | 尺寸、欢迎语、导航、下方内容 | 同尺寸柔和底色；失败显示可见替代说明，不让主面板上跳 |
| 无最近更新 | 分区标题及正常导航 | “这里还没有公开更新”；无虚假日期/计数 |
| 无精选/作品/工具 | 其余阅读顺序 | 对应整区隐藏；无公开工具时隐藏各公开导航中的工具项 |
| 只有 1 篇精选 | 该篇内容 | 单项自然宽度，不占两项空卡位置 |
| 长标题/无封面 | 标题全文和摘要 | 高度自然增长；删除无图槽，不显示灰色图片骨架 |
| 工具维护 | 说明页入口、原因 | 打开不可执行；不影响其他工具 |
| 更新数据读取失败 | 页面身份、可成功读取的其他区域 | 更新区“暂时无法读取更新”与重试；不能伪装成无内容 |

## 5. 公开页线框：P01–P06

| 页面 | 桌面自上而下结构 | 手机重排 | 必须覆盖的状态 |
|---|---|---|---|
| P01 文章/笔记列表 | 公共导航 → 栏目标题/说明 → 标签过滤 → 标题/摘要条目 → 分页 → 页脚 | 过滤折叠但已选可见；条目单列，分页换行 | 无内容、过滤无结果、读取失败、长标题 |
| P02 内容详情 | 导航 → 类型/h1/日期/标签/系列 → 可选封面 → 正文+右目录 → 系列导航 → 普通前后篇 → 评论 → 相关内容 → 页脚 | 正文前可展开目录；标题换行；文末单列 | 无封面、代码/表格过宽、图/公式失败、评论失败、撤回 404 |
| P03 搜索 | 导航 → h1 → 有标签的输入框+搜索按钮 → 类型/标签过滤 → 查询反馈/结果数 → 20 项结果 → 分页 | 筛选折叠，条件标签保留；按钮不小于44px | 未输入、加载、无结果、失败、非法参数、超长输入 |
| P04 作品/工具/资源 | 导航 → 栏目说明 → 列表 → 分页；作品进详情、工具名称进说明页、外部入口独立 | 作品图上文下；工具操作另起行；资源来源可换行 | 维护/停用工具、无演示链接、空目录、无封面 |
| P05 标签/系列/更新 | 标题/简介 → 标签过滤或系列人工序号 → 公开内容列表 → 分页 | 序号与标题不拥挤，全部单列 | 公开空系列、系列归档仍可读、撤回成员消失、无结果 |
| P06 关于/隐私 | 标题 → 简短介绍/正文 → 联系方式或第三方说明 → 关于页友链区 → 页脚 | 同顺序；小头像可选 | 无头像、无友链时隐藏区块，外部链接可识别 |

P02 文末若系列导航与普通前后篇指向相同目标，去重；相关内容最多 3 项，不占空卡。P03 初次主动从搜索入口进入可聚焦输入，浏览器后退时优先恢复列表位置，不强制滚到输入框。P04 资源不代替友链页，友链首版留在关于。

### P03 搜索状态文案示例

未输入：“搜索文章、笔记、动态、作品、工具与资源。”
空结果：“没有找到与‘中文搜索’匹配的公开内容。”保留筛选，提供清除筛选。
失败：“搜索暂时无法完成，你的关键词和筛选已保留。”提供重试。
筛选结果标题：“‘中文搜索’的结果”，元信息显示已选类型与标签；命中片段安全转义。

## 7. 登录 L01 与共用异常页

L01：返回公开站 → “站长登录” → 账号 label/输入 → 密码 label/输入及显示按钮 → 登录 → 分隔说明 → GitHub 登录 → 服务器恢复说明。最大 440px，无注册文案，无营销 Banner。手机可用宽度内单列，软键盘不遮提交区域。

账号/密码失败：“登录未成功，请检查凭据后重试。”不透露账号存在与否。GitHub 取消：“已取消 GitHub 登录，可以重试或使用密码登录。”会话过期：“会话已过期；编辑内容仍保留在原页面，请重新登录后重试保存。”不承诺刷新后仍有内存草稿。

公开 404：站点导航、页面不可用说明、返回首页/搜索；不显示撤回内容的草稿标题。服务器错误：中性说明与重试，不显示数据库堆栈或私有服务。工作台无权限回登录，成功后回合法受保护路径，不跳外站。
