# 个人综合站 Implementation Plan

> **结构调整说明（2026-09-26）：** 本文保留为全系统基线路线图。可执行计划已拆分为总索引和 P0–P5 子计划；后续评审与执行以 [个人综合站-实施计划索引-待审阅.md](个人综合站-实施计划索引-待审阅.md) 及各子计划为准。本文的任务总览不再作为单个执行批次。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** 在不影响现有服务的前提下，交付一个单站长、可恢复、可访问的 SvelteKit + PostgreSQL 个人综合站：公开内容阅读与检索、Markdown 编辑/版本/排期、媒体权限、Giscus 配置、工作台、备份可见性和隔离恢复验收均可追溯。

**Architecture:** 采用 SvelteKit SSR/adapter-node 与 PostgreSQL 分离容器；浏览器只访问服务端路由，服务端通过 Drizzle 与显式 SQL 迁移读写数据库。内容实体、可变编辑稿、不可变版本、公开指针和最多一个未结束排期分离建模；公开查询只读取当前公开版本。媒体采用宿主机持久目录 + 数据库键/元数据，文件授权与正文发布事务分开。发布、排期、备份和恢复均使用幂等状态机、审计记录和可观测时间戳。

**Tech Stack:** SvelteKit（adapter-node）、Node LTS、TypeScript、PostgreSQL、Drizzle ORM/可审阅 SQL 迁移、CodeMirror 6、unified/remark/rehype、Shiki、KaTeX、严格 Mermaid、Argon2id、成熟 GitHub OAuth 客户端（候选 Arctic）、Giscus、Compose。具体版本必须在 Task 1 通过维护状态/兼容性核验后固定。

## Global Constraints

- 产品根目录固定为 /Users/yyb/Projects/personal-site；设计资料只读留在 /Users/yyb/Documents/Codex/2026-09-24/new-chat，不复制进产品源码。
- 首版范围是公开首页、文章、笔记、动态、作品、工具、资源、关于、搜索、标签/系列/全部更新/隐私，以及单站长 /workspace；私人日记、任务、文件工作台、相册、公众注册、独立搜索服务、复杂 CMS、Docker 控制均不实现。
- 首版无公众注册；初始化命令创建唯一站长；密码 Argon2id；GitHub OAuth 绑定稳定数字 ID；不能让首个 OAuth 访客成为站长。
- 内容模型必须保持“稳定 UUID + 可变编辑稿 + 不可变版本 + 当前公开指针 + 至多一个未结束排期”；草稿允许不完整，发布/排期才执行必填校验。
- 公开状态、编辑状态、排期状态、后台归档是独立维度；归档不改变公开状态；撤回原子移除公开指针并取消有效排期。
- 自动保存只更新编辑稿；检查点、手动保存、发布、排期生成不可变快照；恢复历史只生成新稿，不覆盖公开版或有效排期。
- 排期使用 Asia/Shanghai 展示、数据库 timestamptz；30 秒扫描、重启核对并补发有效任务；瞬时失败最多按 1/5/15 分钟三次退避，校验失败不无限重试。
- 公开详情使用 SSR；私有、预览、认证响应 no-store；首版不引入跨请求正文缓存、Redis、Elasticsearch、向量库、图数据库、MinIO 或消息队列。
- Markdown 共享解析/清理规则；不执行原始 HTML、MDX、脚本组件或任意 iframe；Mermaid 出错只影响当前块并保留源码/提示。
- 媒体阈值以资源实测初值执行：图片 20 MiB、PDF 50 MiB、视频 100 MiB、40MP、处理并发 1；低于 15% 磁盘告警、低于 10% 停止新增媒体处理；不得自动清理文件。
- 原图默认私有；展示图与原图分开授权；文件准备完成不等于公开，只有发布事务提交后才授予明确匿名访问。
- 搜索只面向当前公开版本；关键词 NFKC/大小写规范化、空白分片 AND、类型/标签组内 OR、不同组 AND、每页 20；不能泄露草稿/撤回/私有服务；S01–S16 是验收样例。
- 视觉按已批准的综合方案 v2：断点 <768/768–1099/≥1100、浅深主题、目标字体 Noto Sans SC/Space Grotesk/JetBrains Mono、44×44 热区、2px 焦点环、reduced-motion；Banner/作品素材后补，不阻塞无图回退实现。
- 公开首页固定顺序：导航、Banner、介绍、6 条更新、3 篇精选、最多 3 件作品、最多 3 个工具、三组页脚；无公开工具时隐藏工具导航和首页区块。
- 工作台桌面 240px 侧栏、窄屏抽屉；排序必须使用独立“上移/下移”按钮；不得制造批量删除、健康探测、评论待审核数或虚构备份状态。
- 备份必须区分服务器成功、Mac 异地恢复点、Giscus 导出和采集时间；专用 SSH 备份账户/回执通道仅在后续部署阶段受控配置，Web 不持有 SSH 私钥/root/Docker 权限。
- 不修改现有容器（cpa-manager-plus、zotero-pdf2zh-v3、navidrome、cli-proxy-api）；不使用浮动 latest；迁移由独立受控命令执行，不在每个 Web 实例启动时自动迁移。
- 全程遵守交接删除限制：不批量删除文件/目录、不递归清理、不使用等效清理命令；计划不安排删除历史媒体、版本、备份或设计资料。

## Risk Register and Failure Disposition

| 风险 | 检测 | 失败处置 |
|---|---|---|
| 候选库不兼容或失维护 | Task 1 matrix/build | 只替换受影响依赖，保留观察行为并记录。 |
| 中文搜索慢或语义错误 | Task 9 benchmark/S01–S16 | 保留字面语义，使用有界 pg_trgm/字面回退；拒绝部分或假完整结果。 |
| 真实字体改变换行 | Task 12 视觉矩阵 | 保留批准字体和自适应高度，调整间距/容器，不截断文字。 |
| Banner/作品素材未到 | Task 8/12 资源门 | 使用已确认无图/中性回退，图像验收延期，不生成/下载正式资产。 |
| Markdown/Mermaid/SVG 安全问题 | Task 4 安全测试 | 禁用受影响块，保留源码和说明，绝不执行危险 HTML/iframe。 |
| 媒体超内存/磁盘 | Task 5 阈值 | 停止新处理，保留阅读和元数据，显示可操作失败，不删历史文件。 |
| 发布响应丢失/worker 崩溃 | Task 7 fault injection | 先查幂等结果再重试；无法判定就显示未知，不盲发。 |
| OAuth 变化 | Task 1/3 | 固定客户端、状态校验失败即拒绝，保留密码路径；恢复走服务器命令。 |
| 备份回执/恢复不完整 | Task 11 O01–O09 | 保留最后可信恢复点，当前集标失败/未知，可重试。 |
| 现有服务冲突 | Task 11 preflight | 中止本站变更，保留只读证据，现有容器不动。 |
| 测试需要清理 | 每个 Task | 使用隔离 DB/schema 和唯一临时路径，不递归清理；若确需删除只能单文件明确路径并单独复核。 |
