# P1 内容生产链 Implementation Plan

> **For agentic workers:** 使用 superpowers:subagent-driven-development 或 superpowers:executing-plans，按步骤逐项验证。

**Goal:** 交付从 Markdown 编辑到安全媒体、不可变版本、发布、撤回和排期的可恢复内容生产链。

**Architecture:** 预览与公开使用同一解析/清理管线；媒体先受保护暂存，发布事务提交后才公开展示派生图；发布和排期使用事务、锁、幂等状态及审计。

**Spec:** 正式规格主体第 3/4/6 节、功能分册第 2 节、视觉与组件分册第 4.2/4.3/4.4 节。

边界：P1 只通过已记录的服务端接口供 P3 调用，不创建 P3 负责的工作台列表、媒体列表、排期列表或共享工作台布局文件。

## Steps

- [ ] 1. 写解析安全测试：CommonMark、表格、任务列表、代码、目录、脚注、KaTeX、严格 Mermaid；raw HTML、script、MDX、iframe 必须无害；单个 Mermaid 失败保留源码和提示。
- [ ] 2. 实现共享 server renderer、语义 token、44px 热区、2px 焦点环、reduced-motion；代码/表格只在自身容器横滚。
- [ ] 3. 写媒体测试：magic bytes、图片 20 MiB/PDF 50 MiB/视频 100 MiB、40MP、并发 1、pending/processing/ready/failed、失败重试不删除、原图私有。
- [ ] 4. 实现随机 key、宿主持久目录、数据库 metadata、私有 no-store 路由、发布后公开 variant 路由；明确媒体目录环境变量、最小权限、解码器版本和容量采集时间；容量 <15% 警告、<10% 停止新处理，失败重试不删除任何文件。
- [ ] 5. 写编辑测试：2 秒空闲、15 秒连续输入上限、迟到响应、双标签冲突、10 分钟检查点、发布/排期快照、恢复为新稿、导入/导出。
- [ ] 6. 实现 CodeMirror 响应式编辑器：大屏双栏+设置栏、中间宽度抽屉、窄屏编辑/预览标签；保留选区/滚动和真实保存状态。
- [ ] 7. 写发布/排期竞态测试：字段、slug、引用、上传 preflight；立即发布默认取消旧排期，可显式保留；撤回原子取消；由受控 worker/定时器触发，重启补发有效任务；明确时区、锁和幂等键；失败最多 1/5/15 分钟三次。
- [ ] 8. 实现事务发布、历史 URL alias、稳定 RSS ID、重要更新事件和审计。
- [ ] 9. 运行单元、集成、浏览器、fault injection；丢响应先查询结果，无法判定显示未知，不盲目重发。
- [ ] 10. 输出 `docs/verification/P1.md`，完成 `git status`、`git diff` 和相关检查后提交 `feat(p1): 增加可恢复内容生产链`。

## Acceptance

编辑永不直接改公开页面；未发布媒体不可匿名访问；发布失败保留旧公开版；排期取消后不复活；恢复旧版本只生成新稿。
- 预览和公开使用同一清理管线；原图、暂存媒体和失败状态的授权边界通过测试；容量、权限和处理器版本记录在验证报告。
- 自动保存、迟到响应、双标签冲突、发布/排期快照、未知结果和三次失败退避均有可追踪证据。
