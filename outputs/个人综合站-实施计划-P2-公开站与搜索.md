# P2 公开站与搜索 Implementation Plan

> **For agentic workers:** 使用 superpowers:subagent-driven-development 或 superpowers:executing-plans，按步骤逐项验证。

**Goal:** 用已发布公开投影实现首页、六类内容页面、分类页、搜索和公开分发。

**Architecture:** SSR 路由只读当前公开版本；搜索独立页面保存 URL 条件；公开页面 no-store/缓存策略按规格执行；Giscus 仅在允许评论的公开详情按需加载。

**Spec:** 正式规格主体第 1/7/9/11 节、功能分册第 3 节、v1/v2 静态画板索引、视觉分册第 1/3/4 节。
