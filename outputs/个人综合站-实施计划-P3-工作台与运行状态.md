# P3 工作台与运行状态 Implementation Plan

> **For agentic workers:** 使用 superpowers:subagent-driven-development 或 superpowers:executing-plans，按步骤逐项验证。

**Goal:** 交付仅站长可见的工作台管理界面，并诚实显示排期、备份、磁盘、评论配置和服务人工状态。

**Architecture:** 所有写操作经过 owner、CSRF/source 和审计；工作台状态区分未配置、无记录、进行中、成功、失败、陈旧、读取失败；不探测外部服务、不显示虚构计数。

**Spec:** 正式规格主体第 2/9/10 节、功能分册第 4 节、v2 管理画板和控件细稿、视觉分册第 3/4 节。
